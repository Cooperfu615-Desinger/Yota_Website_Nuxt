## 1. 這個功能是什麼

提供未登入玩家建立或恢復身份、登入 Web 官網／遊戲大廳，以及在需要遊戲入口時完成年齡確認。登入 Modal 由 `modalView` 管理多種畫面狀態，登入成功後應依入口返回原目的地。

目前 `LoginModal.vue` 涵蓋 `login`、`register`、`recovery`、`social`、`success`；`AgeGateModal.vue` 以動作佇列方式保存待執行動作。這些是目前原型行為，不代表正式身份服務契約。

## 5. 欄位說明

| 欄位 | 目前規則／顯示 | 正式注意事項 |
|---|---|---|
| 帳號 | 4～20 個半形計數；中英文數字 | server 必須重驗，不能信任前端 regex |
| 密碼 | 前端目前最少 6 碼 | 雜湊、強度、錯誤次數與鎖定待正式規格 |
| 暱稱 | 前端目前至少 2 字 | 字元集、最大長度與敏感詞待確認 |
| 手機 | 目前寫死 `^09\d{8}$` | 需確認國碼、格式與手機登入是否保留 |
| 驗證碼 | Mock 測試值 `123456`；重發等待 60 秒 | 有效期、頻率限制與失敗次數由後端定義 |
| 推薦碼 | 空值或 6／8 碼格式 | 存在性、類型與歸屬由正式 API 定義 |
| 條款審閱 | 需先開啟法律 Modal 才能勾選 | 註冊需傳送條款版本與審閱時間 |
| recovery branch | `phone`、`social`、`unbound` | 不可依帳號字面值推斷正式身份狀態 |

## 6. 狀態說明

| 狀態 | 目前行為 | 正式規格要求 |
|---|---|---|
| `login` | 顯示帳密／手機登入頁籤 | 依 auth API 回應處理成功與錯誤 |
| `register` | 顯示註冊表單 | 建立身份、接受條款並決定是否自動登入 |
| `recovery` | 顯示四步驟假流程 | 需正式 recovery token 與分支判定 |
| `social` | 顯示 provider 確認假畫面 | 需 OAuth redirect、取消與錯誤回復 |
| `success` | 顯示完成並導向目的地 | 需清除一次性資料並保存正式 session |
| `age pending` | 保留待執行 action | 正式 SSR／多請求不可保存閉包函式，應改為識別碼 |
| `cancelled` | 關閉 Modal，原操作不執行 | 明確定義是否返回、保留輸入與再次提示 |

## 7. 查詢、排序與分頁

- 本功能沒有排序與分頁。
- 未來可能需要查詢國碼、法律文件版本、可用登入 provider 與 recovery 分支。
- 國碼清單若由 `/system/dial-codes` 提供，應與手機欄位的格式與登入 API 一致。

## 8. 操作與跳轉

| 操作 | 前提 | 目前結果 | 正式待確認 |
|---|---|---|---|
| 開啟登入 | 由公開頁、大廳受保護頁或遊戲入口觸發 | 打開 Login Modal 並保存目的地 | 是否允許桌機 Header 常駐入口 |
| 帳密登入 | 帳號與密碼通過前端檢查 | Mock 成功後更新 `useAppState` | token、refresh、錯誤與鎖定 |
| 手機登入 | 手機與驗證碼欄位有效 | Mock 驗證 | 是否正式保留、國碼與 SMS 供應商 |
| 註冊 | 表單有效且完成條款審閱 | Mock 建立身份 | 自動登入、條款版本與推薦碼 |
| 忘記密碼 | 帳號確認 | Mock 分支與重設 | 公開 recovery 四支 API 與安全政策 |
| 年齡確認 | 入口要求 Age Gate | 確認後執行暫存 action | 每次、每日或每 session 的法遵規則 |
| 關閉／取消 | Modal 開啟 | 關閉並保留或清除部分狀態依目前元件 | 各步驟取消後的返回語意 |

## 9. 頁面狀態

需分別定義表單初始、輸入中、欄位錯誤、送出中、服務失敗、帳號不存在、憑證錯誤、帳號鎖定、驗證碼過期、第三方取消、年齡拒絕與成功返回。現有原型主要覆蓋前端欄位檢查與 Mock 成功，正式網路錯誤與安全錯誤尚未驗證。

所有使用 `<Teleport>` 的登入、法律與 Age Gate Modal 必須在 layout 的 `<ClientOnly>` 範圍內，避免 SSG hydration mismatch。

## 14. 這個功能需要的資料

- 登入／註冊 request 與 response、token／refresh、expires、profile。
- provider、國碼、驗證碼冷卻秒數、錯誤碼與安全風險狀態。
- protected destination 的 path、query 與一次性消費狀態。
- 法律文件 ID、版本、語言、內容、審閱時間與同意狀態。
- 年齡確認的觸發原因、確認範圍、保存生命週期與法遵紀錄。
