## 1. 這個功能是什麼

本功能讓玩家知道今天的簽到與任務進度、查看活動與獎勵條件、瀏覽不同排行榜，以及取得 Web／APP 使用與加入主畫面的教學。公開活動／排行榜／教學可先瀏覽；每日簽到、個人任務與領取操作必須受到登入與服務端資格保護。

玩家應能理解活動期間、獎勵、更新狀態、個人排名脈絡，以及 Web 與 APP 的功能邊界。瀏覽器時間與前端 seed data 只能作原型顯示，不能取代服務端時間、資格與結算結果。

## 2. 這個功能不做什麼

| 不在本章範圍 | 負責位置 |
|---|---|
| 獎勵卡、優惠碼與贈禮資產狀態機 | `web-08-rewards-promotions-gifts.md` |
| 錢包、儲值、交易與正式獎勵入帳 | `web-07-finance.md` 與後端／帳務契約 |
| 公開頁共用內容與 CMS／SEO 服務 | `web-02-public-site.md` |
| 正式活動後台、排行榜結算與獎勵發放服務 | 活動／後端／營運契約；本章只描述前台邊界 |
| APP 專屬畫面、固定畫布與原生安裝流程 | APP 規格僅作差異參考；Web 教學不承諾原生安裝 |

## 3. 名詞說明

| 名詞 | 定義 |
|---|---|
| 每日簽到 | 以活動期別與伺服器日期判定每日可完成的一次操作 |
| 里程碑 | 達到指定簽到／任務進度後可領取的階段獎勵 |
| 補簽 | 對符合條件的漏簽日期進行補完成，可能需要成本與限制 |
| 活動 | 有期間、資格、玩法、獎勵與狀態的營運內容 |
| 排行榜 | 依倍數、贏分或財富等指標呈現排名的公開／登入後功能 |
| 伺服器時間 | 活動、簽到、結算與獎勵資格的可信時間來源 |
| 加入主畫面 | 以瀏覽器提供 Web shortcut 的教學，不等於原生 APP 安裝 |

## 5. 欄位說明

| 欄位 | 顯示內容 | 限制與目前狀態 |
|---|---|---|
| check-in day | 日曆日期、序號、已簽／今日／漏簽狀態 | 目前共 31 天；正式由活動期別與伺服器時間判定 |
| daily reward | 幣別、數量、領取結果 | 第 10／15／20 天的正式幣別與是否為獎勵卡待封存 |
| milestone | 里程碑日、獎勵、可領／已領 | 目前候選為第 5、7、10、15、20、25、30 天 |
| make-up | 可補日期、成本、確認結果 | 目前候選每日成本 100；正式上限與資格待確認 |
| event | 標題、摘要、狀態、期間、獎勵、類型 | `siteContent.events` 為靜態資料；正式由 CMS／活動服務提供 |
| leaderboard | Tab、名次、玩家名稱、分數、單位、更新資訊 | 目前為 preview／top3／rest；不可宣稱即時結算 |
| tutorial step | 平台、瀏覽器、步驟、外部連結 | 需標示 OS 版本差異、風險提示與失效 fallback |

## 6. 狀態說明

| 狀態 | 目前／目標行為 |
|---|---|
| `not-started`／`today`／`completed` | 依活動期別與伺服器日期辨識簽到可操作性 |
| `missed`／`make-up-available` | 顯示漏簽與補簽成本、資格及確認流程 |
| `milestone-claimable`／`claimed` | 里程碑只能領取一次，成功結果需可回讀 |
| `active`／`upcoming`／`ended` | 活動依服務端有效期間與狀態分組 |
| `loading`／`empty`／`error` | 每日資料、活動、排行榜與教學均需各自可觀察 |
| `unranked`／`not-eligible` | 清楚說明玩家未上榜或不具活動資格的原因 |

目前頁面主要用 seed data、`useState` 與本地計時模擬；正式版不可讓瀏覽器時間、頁面 state 或畫面顏色成為資格與獎勵的唯一依據。

## 7. 查詢、排序與分頁

- 活動需支援進行中、即將開始、已結束與類型／資格的分組或篩選；目前沒有正式分頁與查詢 API。
- 排行榜需定義榜單類型、名次排序、更新時間、結算版本與我的排名；大型榜單需由 API 定義 cursor 或分頁。
- 每日簽到以活動期別與日期查詢，不以瀏覽器端任意排序或改寫日曆狀態。
- 教學步驟依平台與瀏覽器顯示；外部下載／加入主畫面連結需有版本與失效處理。

## 8. 操作與跳轉

### 8.1 每日簽到與里程碑

1. 玩家進入 `/lobby/daily`，取得伺服器時間與本期簽到資料。
2. 玩家點擊今日簽到；未登入時先要求登入並保留目的地。
3. 成功後更新今日狀態、獎勵與里程碑進度；不可重複簽到或領取。
4. 玩家可查看漏簽日，在確認成本後進行符合資格的補簽。

目前 `siteContent.dailyCheckin.dailyRewards` 共 31 天，里程碑候選為第 5、7、10、15、20、25、30 天；這些值需與正式活動規則同步。

### 8.2 活動與排行榜

活動卡可開啟詳情，依資格與狀態導向儲值、遊戲、簽到或登入；排行榜可切換「倍數榜」「贏分榜」「富豪榜」，顯示前三名與後續名次。活動與排行榜切換後不可沿用另一功能的 Tab、日期或舊資料。

### 8.3 教學與加入主畫面

教學提供平台介紹、遊戲使用方式、Web／APP 差異與 iOS／Android 加入主畫面步驟。導流可返回首頁、登入或大廳；外部連結須在正式規格補上版本、檔案完整性、風險提示與失效 fallback。

## 9. 頁面狀態

需覆蓋未登入、載入中、無資料、活動未開始、活動已結束、今日可簽、已簽、漏簽、補簽確認、里程碑可領／已領、餘額不足、重複領取、資格不足、排行榜未上榜、榜單服務失敗、教學連結失效與返回原入口。任何獎勵發放失敗都要保留可查詢結果，不可只顯示成功。

## 14. 這個功能需要的資料

- 活動期別、伺服器時間、玩家資格、每日簽到紀錄、連續進度、補簽成本與里程碑領取紀錄。
- 每日獎勵、獎勵卡／錢包／信箱 reference、發放狀態、冪等鍵與失敗補償資訊。
- 活動 ID、標題、期間、狀態、類型、資格、玩法、獎勵、導流路徑與內容版本。
- 排行榜 ID、榜單類型、名次、玩家公開識別、數值、單位、更新時間、結算版本與我的排名。
- 教學平台、OS／瀏覽器版本、步驟、外部 URL、版本資訊與失效 fallback。

目前 `siteContent.ts`、`useState` 與 local timer 只代表 Web 原型資料來源；正式接入後以活動／排行榜服務為權威。
