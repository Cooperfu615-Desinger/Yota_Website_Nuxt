## 1. 這個功能是什麼

讓已登入玩家查看與管理自己的身份資料、帳號綁定、VIP 資訊、頭像與遊戲紀錄，並從大廳 Header 或導覽進入會員頁。會員頁只處理自己的資料，不等同於聊天中的其他玩家公開資料卡。

目前 `/lobby/member` 與玩家資料彈窗共用 `MemberProfileView.vue`；分頁為基本資料、帳號綁定、VIP、登入紀錄、遊戲紀錄。帳號綁定由 `AccountBindingPanel.vue` 共用，授權視窗使用 `SocialAuthorizationDialog.vue`。

## 5. 欄位說明

| 欄位 | 目前內容／限制 | 正式注意事項 |
|---|---|---|
| account | 帳號識別；通常不可由玩家任意修改 | 以正式身份 API 為準 |
| name | 暱稱 | 長度、敏感詞與修改頻率需確認 |
| email | 基本資料唯讀；去除前後空白、格式有效、六碼驗證成功才保存 | 舊值無驗證結果顯示待驗證，鎖定原地址；正式寄信、唯一性及有效期未實作 |
| birthday | `YYYY-MM-DD` 候選格式 | 合法日期與修改限制尚未完整定義 |
| bio | 玩家簡介；目前有長度候選 | 正式限制與敏感內容規則待確認 |
| avatar／avatarId | 目前 12 個 emoji，部分依 VIP5 解鎖 | 正式 default avatar、上傳與 ID 模型待確認 |
| VIP | 等級、稱號、升級／保級資訊 | 需結構化門檻與權益，不能只顯示文案 |
| game record | 目前 100 筆隨機 Mock | 正式以 server id、時間與 gameKey 關聯 |

## 6. 狀態說明

| 狀態 | 目前行為 | 正式規格要求 |
|---|---|---|
| 未登入 | 顯示登入／註冊導引 | 不可讀取玩家私有資料 |
| profile loading | 目前沒有正式 API loading | 需處理讀取中、失敗與重新載入 |
| profile editable | 暱稱與簡介可編輯，首次生日需確認；基本資料不能寫入 Email 或綁定 | 正式保存、鎖定與衝突由服務端決定 |
| binding connected | 顯示已綁定，無解除、更換或重複綁定入口 | 更正／解除另需產品及服務契約，不由原型擴充 |
| binding unavailable | 目前缺少完整錯誤路徑 | 需明確 provider 失敗、取消與重試 |
| VIP progress | 目前主要是文案／Mock 數值 | 儲值 AND 投注雙條件與保級規則需結構化 |
| records empty／error | 目前以假資料為主 | 正式需無資料、失敗、分頁與時間範圍狀態 |

## 7. 查詢、排序與分頁

- 會員頁本身以頁籤切換，沒有一般排序。
- 遊戲紀錄目前由前端產生 100 筆資料，尚未提供正式日期範圍、排序、分頁與 server cursor。
- VIP 進度是玩家當前身份的摘要，不應由前端自行計算正式升級結果。
- 綁定列表以 provider 固定順序顯示；正式是否依後端可用 provider 動態排序待確認。

### 8.1 五種綁定與 Email 驗證（2026-10-14 已確認方向／目前 Web 原型）

- 對齊 APP `3f351d1`：手機使用 `123456` 示範碼，Email 每次發送產生六碼示範碼並保留前導零；畫面顯示測試碼，不實際寄信或傳簡訊。
- 兩種聯絡資料各自維持 60 秒重發限制。未滿六碼不能確認，錯碼不寫入；返回修改仍受倒數限制，重發清空輸入並改用當次碼。60 秒不代表驗證碼有效期。
- 新信箱驗證成功才保存地址與 `accountBindings.email`。舊資料有地址但沒有驗證旗標時，保留原地址並顯示待驗證，不能改成另一地址。基本資料只顯示結果；一次性確認只列生日。
- Google／APPLE／FB 走連線 → 允許或取消 → 綁定中 → 授權成功 → 回原綁定頁。授權確認可取消或 ESC；只關閉授權層。離開綁定分頁或身分變更會取消未完成操作，不能延遲補寫成功。
- 綁定只更新目前身分的聯絡資料／對應狀態，不更動帳號、ID、登入來源、VIP、邀請碼或金融狀態；訪客綁定不自動升級身分。LINE 登入保留，綁定頁不新增 LINE。
- 基本資料、其他綁定的連續更新合併至最新狀態；完成結果保存在既有 `jh_userInfo`，重新整理還原。草稿、碼與倒數不保存，登出清除示範身分。這不代表正式帳號、跨裝置或金融持久化。
- 社群登入與綁定共用授權顯示但分開執行：新社群示範身分初始化對應連結，不自動產生 Email 驗證。未自行新增 VIP 綁定門檻。

## 9. 頁面狀態

需定義 profile 初次 loading、未登入、資料讀取失敗、資料編輯中、送出中、欄位錯誤、Email 鎖定、provider 綁定中／失敗／取消、VIP 無資料、紀錄無資料／失敗、頭像被鎖定與登出後返回。現有原型主要覆蓋成功顯示與部分鎖定狀態。
