# WEB 直播功能搬移

## 來源與範圍

- APP 來源：GitLab main `3e40a23782776d1a0d4d39b22f8f76dcae9a0976`。
- 對照：`LiveCenter.tsx`、`LiveRoomDemo.tsx`；沿用 APP 的 `live-host-demo.png` 示範素材。
- WEB 入口：左方「遊戲大廳」正下方的「直播」，路由 `/lobby/live`。
- 登入：側欄入口沿用登入彈窗；直接開網址時，未登入只顯示登入引導。
- 不修改 APP、錢包、既有遊戲篩選或其他頁面的功能。

## 搬移內容

1. 直播大廳：六張主播卡、直播／下播狀態、人數、分類、主播與標題搜尋、關注及最愛篩選。
2. 直播預告：分類與搜尋欄位、尚無預告的空狀態；沒有額外新增預約或提醒。
3. 直播排行：收禮／送禮、月／週／日、前三名、其餘名次及自身未上榜狀態。
4. 我的：關注數、觀看數、觀看紀錄、免費愛心贈禮紀錄。
5. 房間：返回列表、標題／主播／分類／人數、關注、播放／暫停／靜音示意，以及聊天／直播介紹／本場支持榜。
6. 聊天：純文字 200 字元上限、空白阻擋、Enter 送出、自動捲動；免費愛心更新聊天室與贈禮紀錄。

## 保留的原型規則與限制

- 靜態圖片不是串流；播放與聲音按鈕只改變示意狀態。
- 訊息只在本機顯示；愛心不扣款；榜單為固定示範資料，不隨送禮更新。
- 下播房間仍可進入、聊天、送出免費愛心，與 APP 一致。
- 只記錄直播中的觀看；同一主播不重複計數，最近觀看排在最前。
- 關注、觀看、贈禮與篩選在同次直播頁內切換時保留。離開頁面、重新整理或切換登入身分時重置。
- 房間聊天、播放及靜音狀態於離開房間後重置。
- 贈禮空狀態文案依既有可操作的免費愛心功能描述，不誤導為「尚未能留下紀錄」。

## WEB 版面

- 使用 WEB 字型、深紫／金色設計與自然頁面高度，不使用 APP 1280×720 縮放畫布。
- 主播卡桌機三欄、1199px 以下兩欄、599px 以下一欄。
- 房間 1200px 起左右分欄；較窄畫面改成播放區在上、互動區在下。
- 聊天區獨立捲動，頁面保留既有手機底部導覽空間。

## 驗證方式

```sh
PATH="/opt/homebrew/opt/node/bin:$PATH" node --test tests/live.test.mjs
PATH="/opt/homebrew/opt/node/bin:$PATH" npm run generate
PATH="/opt/homebrew/opt/node/bin:$PATH" node tests/live.browser.mjs
git diff --check
```

瀏覽器測試使用獨立 Chromium 與暫時的本機靜態服務，驗證產生後的頁面與 baseURL。測試結束會關閉服務與瀏覽器；截圖路徑由測試輸出提供，不提交截圖或 `docs/`。

涵蓋登入、組合篩選、關注同步、房間控制、訊息、免費禮物與錢包不變、下播行為、紀錄、排行榜、離頁／重整清除狀態，以及 1440／768／390／320px 版面與手機操作。

既有全套 Node 測試在 Node 25 直接執行時，`giftRequest.ts` 的無副檔名相對匯入會導致解析失敗。本次未修改該無關原始碼；以臨時 TS 副檔名解析器補足測試環境後，全套 38 項通過。直播自身六項不需此解析器即可通過。
