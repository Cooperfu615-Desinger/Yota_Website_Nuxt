專案定位

Nuxt 3 SSG 靜態網站，分為官網（/）與遊戲大廳平台（/lobby）兩套獨立架構。

內容中心

內容集中在 data/siteContent.ts，樣式主題集中在 assets/css/main.css。

部署方式

GitHub Actions 自動 build，不再依賴手動提交 docs/。Push to main 後約 2–5 分鐘完成部署。

技術堆疊

  • Nuxt 3 + Vue 3，SSG 模式
  • Tailwind CSS + 自訂 assets/css/main.css
  • Nuxt useState + composables（SSR-safe 狀態管理）
  • Google Fonts：Noto Sans TC
  • Nitro static preset，輸出至 docs/
  • GitHub Pages，baseURL：/Yota_Website_Nuxt/

官網首頁（/）
  • 桌機展開：200px；收合：60px（icon-only）
  • 手機：overlay 模式，`transform: translateX(-100%)` 動畫
  • 狀態以 Nuxt useState 跨元件共享

遊戲視圖（GameView，Stake 風格）

  • 點擊遊戲卡後，/lobby/index.vue 以 v-if 替換顯示 <LobbyGameView>
  • Iframe 固定 aspect-ratio: 16/9，非全螢幕
  • 控制列：全螢幕 icon / 品牌名 / 試玩 & 真錢模式切換 Tab
  • 下方：供應商資訊、遊戲名、RTP 標籤、遊戲描述、規格表
  • 試玩無需登入；真錢模式未登入觸發 LoginModal

Web館按鈕

  • 位置：position: fixed; top: 64px; right: 12px（Header 正下方）
  • 尺寸：padding: 14px 28px，字體 18px，圓角膠囊形
  • 效果：紫色漸層 + 脈衝光暈動畫（web-btn-pulse）
  • 點擊：router.resolve('/h5').href 另開新分頁

SSG 已知地雷（必讀）

地雷說明處理方式
<Teleport> mismatchSSG 下 Teleport 造成全站 @click 失效一律包入 <ClientOnly>
appManifestNuxt 3.9+ build ID 版本衝突 → hydration 失敗nuxt.config.ts 永遠設 appManifest: false
.nojekyllJekyll 抑制 _nuxt/ 目錄generate 指令自動建立
useState vs refSSG hydration 狀態不一致跨元件共享狀態一律用 useState
