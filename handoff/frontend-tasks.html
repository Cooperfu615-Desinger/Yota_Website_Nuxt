📐 原型參考說明

  • 原型網址：https://cooperfu615-desinger.github.io/Yota_Website_Nuxt/　可直接在瀏覽器開啟瀏覽所有頁面與互動效果。
  • 原型用途：僅作為視覺設計與功能邏輯的參考依據，前端不需沿用原型的程式碼或技術架構，以正式 Figma 設計稿為開發準則。
  • Figma 設計稿：色彩系統、元件規格、各頁面 Layout 皆以 Figma 為主要交付標準，原型僅作為互動邏輯輔助參考。
  • 美術資源：Banner 圖、活動圖、遊戲封面（AVIF 格式）由美術團隊提供，原型中已使用的圖檔可供參考尺寸與裁切方式。
  • 兩套 Layout：官網（含 Header + 底部導覽）與遊戲大廳（含 Header + 側邊欄）為獨立 Layout，切換點為進入 /lobby/ 路由後。
  • 後端 API：後端仍在開發中，P3 項目暫不實作，先以靜態 mock 資料完成頁面功能，待後端就緒再行串接。
