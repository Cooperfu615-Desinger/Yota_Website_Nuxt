# 第一章：註冊、登入與帳號安全

- 章節狀態：草稿，待產品確認
- 版本：0.1
- 建立日期：2026-07-31
- 適用對象：產品營運人員、客服人員
- 對應功能：年齡確認、會員註冊、帳號密碼登入、第三方登入、手機登入入口、訪客登入入口

## 1. 本章目的

本章說明玩家如何進入官網、建立會員帳號、使用帳號密碼登入，以及在登入流程中可能遇到的限制與錯誤。

客服閱讀本章後，應能回答以下問題：

- 註冊帳號可以使用哪些字元？長度如何計算？
- 密碼最少需要幾個字元？目前是否有最大長度？
- 玩家代理推薦碼是否必填？格式為何？代理推廣碼與玩家代理推薦碼有什麼不同？
- 為什麼玩家無法送出註冊表單？
- 登入失敗時，應先確認哪些資訊？
- 玩家未滿 18 歲或拒絕年齡確認時，應如何處理？
- 訪客、手機驗證碼與第三方登入是否可以當作正式功能對外說明？

## 2. 名詞說明

| 名詞 | 說明 |
|---|---|
| 帳號 | 玩家用來登入平台的主要識別文字。 |
| 暱稱 | 顯示給其他玩家看的名稱，不等同於登入帳號。 |
| 密碼 | 玩家使用帳號登入時的驗證資訊。客服不可要求玩家提供。 |
| 玩家代理推薦碼 | 註冊時可選填、由玩家輸入的代理推薦識別碼；格式為大寫英數 8 碼。 |
| 代理推廣碼 | 代理商對外使用的推廣識別碼；格式為大寫英數 6 碼，不是玩家註冊欄位。 |
| 平台帳號 | 使用帳號與密碼建立的本地會員帳號。 |
| 第三方登入 | 使用 LINE、Facebook、Apple 或 Google 等外部帳號進入平台。 |
| 年齡確認 | 玩家進入限制級遊戲內容前，確認已年滿 18 歲的流程。 |
| 驗證碼 | 由系統傳送給玩家的一次性驗證資訊。客服不可要求玩家提供。 |

## 3. 正式產品規則

以下規則是本章目前可以作為正式說明的內容。

### 3.1 年齡限制

- 巨亨ONLINE WEB館屬限制級遊戲內容，玩家必須年滿 18 歲才可以進入遊玩。
- 未滿 18 歲的玩家不得使用限制級遊戲功能。
- 客服不得提供任何繞過年齡確認、借用他人帳號或規避年齡限制的方式。
- 「下次不再提示」只代表提示顯示偏好，不代表免除年齡資格或免除其他身分驗證。

### 3.2 帳號規則

- 帳號為必填欄位，長度為 1–50 個 rune。
- 帳號允許使用任何字元，包含中文、英文、數字、空格、底線與特殊符號。
- 帳號不可在開頭或結尾使用空格；帳號中間的空格允許使用。
- 帳號區分大小寫，例如 `User` 與 `user` 是不同帳號。
- 帳號是唯一值，不可與其他會員重複。
- 帳號的長度以 rune 計算，不以 byte 或半形字元換算。
- 正式後端必須重新驗證帳號格式，不能只依賴前端畫面限制。

#### 帳號長度計算範例

| 輸入範例 | 計算方式 | 結果 |
|---|---|---|
| `ABCD` | 4 個 rune | 符合長度 |
| `巨亨` | 2 個 rune | 符合長度 |
| `巨亨 ONLINE` | 8 個 rune，包含中間空格 | 符合長度 |
| `A巨` | 2 個 rune | 符合長度 |
| ` ABC` | 開頭為空格 | 不符合 |
| `ABC ` | 結尾為空格 | 不符合 |
| `ABC-123` | 7 個 rune，包含特殊符號 | 符合長度 |

### 3.3 密碼規則

- 密碼為必填欄位，長度為 6–100 個字元。
- 密碼允許使用任何字元；目前沒有另外限制中文、英文、數字、空格或特殊符號。
- 註冊與忘記密碼重設時，都必須符合 6–100 個字元的要求。
- 兩次輸入密碼必須完全一致。
- 密碼前後空格屬於輸入內容的一部分，不應由前端或後端自動移除。
- 連續錯誤次數與鎖定時間尚未在本規範中定義；客服不得自行增加規則或承諾例外。
- 密碼屬於敏感資訊，客服不得要求玩家提供、代填或透過聊天傳送。

### 3.4 暱稱規則

- 暱稱為必填欄位，長度為 1–100 個字元。
- 暱稱是公開顯示名稱，不等同於登入帳號。
- 暱稱可以與其他玩家重複，也可以與自己的登入帳號相同。
- 暱稱的允許字元規則若未在其他正式契約定義，客服不要自行增加限制。

### 3.5 玩家代理推薦碼與代理推廣碼規則

- 註冊頁的玩家代理推薦碼為選填欄位，格式為大寫英文字母與數字，固定 8 碼。
- 代理商對外使用的代理推廣碼格式為大寫英文字母與數字，固定 6 碼。
- 玩家代理推薦碼與代理商推廣碼是不同用途的代碼，不應在客服說明中統稱為「6 碼或 8 碼推廣碼」。
- 小寫英文字母、空格、特殊符號或長度不符的代碼，不符合對應代碼的格式。
- 代碼格式正確不代表一定有效；是否存在、是否啟用、是否已使用或是否符合活動資格，應由正式系統判斷。
- 客服不得自行替玩家指定代理歸屬或承諾推廣獎勵。

### 3.6 會員條款

- 玩家完成註冊前，必須先閱讀並完成會員條款審閱。
- 正式註冊請求需記錄玩家同意的條款版本。
- 玩家未完成條款審閱時，不應建立正式會員帳號。
- 會員條款與隱私政策的完整內容，以正式發布版本為準。

## 4. 年齡確認操作流程

### 4.1 正常流程

1. 玩家從官網進入需要限制級資格的遊戲內容。
2. 系統顯示限制級提示，說明進入「巨亨ONLINE WEB館」前須確認年滿 18 歲。
3. 玩家確認自己已年滿 18 歲。
4. 玩家按下確認按鈕。
5. 系統關閉提示並繼續原本要執行的操作。

### 4.2 玩家關閉或拒絕提示

1. 玩家按下關閉按鈕、點擊提示外部區域或離開頁面。
2. 系統不應繼續執行原本需要年齡確認的遊戲操作。
3. 客服應請玩家重新進入功能並完成正確的年齡確認。
4. 若玩家表示未滿 18 歲，客服應停止提供遊玩引導，並依公司未成年處理政策回覆。

### 4.3 客服判斷重點

- 玩家已登入，不代表一定已完成本次年齡確認。
- 玩家勾選「下次不再提示」，不代表帳號年齡資料已被驗證。
- 若年齡提示反覆出現，先確認玩家是否完成確認、是否切換頁面或清除瀏覽器資料，再判斷是否為系統問題。
- 若玩家要求客服代為繞過提示，應拒絕此要求並說明年齡限制是必要條件。

## 5. 會員註冊操作流程

### 5.1 進入註冊頁面

玩家可以從以下位置進入註冊流程：

- 官網上方的登入入口。
- 需要登入的功能頁面中的「登入／註冊」入口。
- 登入視窗中的「立即註冊」按鈕。

若玩家從受保護功能進入註冊，註冊完成後應回到原本想使用的功能；若正式版本未保留原目的地，客服應請玩家重新進入該功能。

### 5.2 填寫註冊資料

玩家依序填寫：

1. 帳號。
2. 暱稱。
3. 密碼。
4. 確認密碼。
5. 玩家代理推薦碼（選填）。
6. 開啟並閱讀會員條款。
7. 完成條款審閱後送出註冊。

### 5.3 表單送出前檢查

送出前應確認：

- 帳號為 1–50 個 rune，且開頭與結尾不得為空格。
- 暱稱為 1–100 個字元。
- 密碼為 6–100 個字元。
- 兩次密碼完全一致。
- 玩家代理推薦碼為空，或為大寫英數 8 碼。
- 已完成會員條款審閱。

任一條件不符合時，系統應阻止註冊送出，並在對應欄位或表單區域顯示原因。

### 5.4 註冊送出後

正式產品流程應由後端重新驗證所有欄位，並依結果回傳成功或失敗原因。

成功時：

- 建立正式會員帳號。
- 保存帳號、暱稱、玩家代理推薦碼與條款版本等註冊資料。
- 顯示註冊成功結果。
- 後續是否自動登入，須以正式產品決策與 API 回應為準，目前不在本章自行定義。

失敗時：

- 不應建立半成品會員帳號。
- 應保留玩家可重新修改的欄位內容，但密碼等敏感欄位是否清空以正式版本安全設計為準。
- 應顯示足以讓玩家修正問題的訊息，不應暴露不必要的帳號或系統資訊。

## 6. 帳號密碼登入操作流程

### 6.1 正常流程

1. 玩家開啟登入視窗。
2. 選擇「帳號密碼」登入方式。
3. 輸入帳號。
4. 輸入密碼。
5. 按下登入。
6. 系統驗證帳號與密碼。
7. 驗證成功後建立登入狀態，進入會員可使用的頁面或返回原本要使用的功能。

### 6.2 登入前檢查

帳號欄位仍需符合帳號格式檢查。玩家若輸入開頭或結尾有空格的內容，應先修正後再送出；中間空格與特殊符號本身不需要移除。

密碼欄位不可由客服代為輸入或確認內容。若玩家忘記密碼，應引導至「忘記密碼與帳號恢復」章節的正式流程。

### 6.3 登入成功

- 系統建立有效的會員登入狀態。
- 玩家可以使用需要登入的功能。
- 若玩家是從受保護頁面進入登入，系統應返回原本的功能位置；若未成功返回，客服可請玩家重新點選該功能。
- 客服不得要求玩家提供登入後畫面中的敏感資料。

### 6.4 登入失敗

若帳號或密碼驗證失敗，客服應先請玩家確認：

- 是否輸入正確帳號，而不是暱稱。
- 是否誤輸入開頭或結尾空格，或在不預期的位置輸入空白。
- 是否開啟了錯誤的輸入法或 Caps Lock。
- 是否使用最近重設後的新密碼。
- 是否有看到帳號停權、功能維護或其他明確提示。

客服不得要求玩家將密碼貼到客服對話中測試。

## 7. 其他登入入口的說明原則

目前前端畫面有手機驗證碼、訪客、LINE、Facebook、Apple、Google 等入口，但其中部分仍屬前後端串接或產品決策待確認項目。未完成正式確認前，不得直接對玩家承諾其一定可用。

### 7.1 第三方登入

正式目標流程預計包含：

1. 玩家選擇第三方登入服務。
2. 系統取得第三方授權網址。
3. 玩家完成第三方授權。
4. 系統接收 callback 並判斷是否已有對應會員。
5. 已註冊玩家登入成功。
6. 尚未註冊玩家依正式流程補充資料並建立帳號。

目前 API 工作清單仍標記相關端點為製作中，因此客服只能依正式上線版本的畫面與公告回答。若玩家遇到第三方登入失敗，應記錄服務商、發生時間、錯誤畫面與瀏覽器，不要求玩家提供第三方帳密。

### 7.2 手機驗證碼登入

手機驗證碼登入是否為正式保留功能、支援哪些國碼與驗證碼規則，尚待產品確認。未確認前，不應以目前前端顯示的測試驗證碼或國內手機格式作為正式說法。

### 7.3 訪客登入

訪客登入是否列入正式產品功能尚待確認。若正式版本保留，必須另行定義訪客資料保存期限、可使用的功能、是否可轉換為正式會員及登出後資料處理方式。

## 8. 常見情境與處理矩陣

| 玩家情況 | 玩家可能看到的結果 | 客服第一步 | 後續處理 |
|---|---|---|---|
| 帳號少於 1 個 rune 或超過 50 個 rune | 顯示帳號長度不足或超過限制 | 請玩家依 rune 長度重新調整 | 不以半形字元或 byte 數量計算 |
| 帳號開頭或結尾有空格 | 顯示帳號格式不符 | 請移除開頭與結尾空格 | 中間空格可以保留 |
| 帳號包含特殊符號 | 不應僅因特殊符號而拒絕 | 確認是否為長度、前後空格或帳號重複問題 | 不要自行宣稱特殊符號不允許 |
| 帳號已被使用 | 顯示帳號重複或會員已存在 | 請玩家更換帳號，或確認是否已有帳號 | 不可承諾人工重複建立 |
| 密碼少於 6 個或超過 100 個字元 | 無法送出或顯示密碼長度錯誤 | 請重新設定 6–100 個字元的密碼 | 不要求玩家提供密碼內容 |
| 兩次密碼不一致 | 顯示密碼不一致 | 請重新輸入兩次密碼 | 若仍發生，請改用手動輸入並確認輸入法 |
| 玩家代理推薦碼小寫或非 8 碼 | 顯示推薦碼格式錯誤 | 請確認為大寫英數 8 碼 | 格式正確仍需由系統判斷有效性 |
| 未閱讀會員條款 | 註冊按鈕不可用或提示需審閱 | 引導玩家開啟並完成條款審閱 | 若條款無法開啟，記錄頁面與瀏覽器後升級 |
| 帳號不存在或密碼錯誤 | 登入失敗 | 請確認登入帳號與輸入方式 | 忘記密碼者引導正式恢復流程 |
| 玩家輸入暱稱登入 | 登入失敗 | 說明暱稱不是登入帳號 | 請玩家改用註冊帳號 |
| 年齡未滿 18 歲 | 不得進入限制級遊戲內容 | 停止遊玩引導 | 依未成年處理政策回覆 |
| 年齡提示無法關閉 | 無法繼續原本操作 | 請重新載入並確認是否按下確認 | 可重現時記錄裝置、瀏覽器與頁面後升級 |
| 第三方登入失敗 | 可能返回登入頁或顯示錯誤 | 記錄第三方服務、時間與錯誤訊息 | 不要求第三方帳密，依正式支援流程升級 |
| 登入後立刻回到未登入狀態 | 會員功能仍要求登入 | 確認瀏覽器是否阻擋 Cookie 或隱私模式 | 記錄裝置與瀏覽器版本後升級 |
| 顯示系統維護或功能停用 | 無法進入功能 | 確認是否為全站公告或功能維護 | 不承諾確切恢復時間，依公告內容回覆 |

## 9. 客服檢查清單

處理註冊或登入問題時，客服依序確認：

1. 玩家使用的是官網、APP 還是其他頁面。
2. 發生問題的完整時間與時區。
3. 使用的功能：註冊、帳號密碼登入、手機登入或第三方登入。
4. 玩家看到的完整錯誤訊息或截圖。
5. 帳號是否為 1–50 個 rune，且開頭與結尾沒有空格。
6. 玩家是否把暱稱誤當成登入帳號。
7. 是否近期重設過密碼。
8. 是否已完成會員條款審閱。
9. 是否為特定瀏覽器、裝置或網路才發生。
10. 是否有維護、停權、凍結或功能停用提示。

不得確認或要求：

- 完整密碼。
- 簡訊驗證碼。
- 第三方服務登入密碼。
- 讓玩家將帳號密碼截圖給客服。

## 10. 升級條件

符合以下任一情況，應保留錯誤資訊並升級給產品或技術團隊：

- 所有格式均符合，但正式系統仍拒絕註冊。
- 條款頁面無法開啟、內容空白或無法完成審閱。
- 玩家完成註冊後沒有收到明確結果，且再次註冊顯示狀態不一致。
- 登入成功後立即被登出，且排除 Cookie、隱私模式與網路問題。
- 年齡確認完成後，系統仍無法執行原本的操作。
- 第三方授權完成後卡在 callback、重複跳轉或無法返回官網。
- 多位玩家同時回報相同登入或註冊錯誤。
- 顯示錯誤碼與本手冊或正式公告不一致。
- 玩家帳號出現停權、凍結或功能停用提示，但客服無法取得正式狀態說明。

升級時至少附上：功能名稱、發生時間、帳號識別資訊、裝置與瀏覽器、操作步驟、錯誤訊息、是否可重現，以及已嘗試過的處理方式。不得附上玩家密碼或一次性驗證碼。

## 11. 客服回覆範例

### 11.1 帳號規則

> 官網帳號長度為 1–50 個 rune，可以使用中文、英文、數字、空格與特殊符號；但開頭與結尾不能有空格，中間空格可以保留。帳號區分大小寫且不能與其他帳號重複，請依提示調整後重新輸入。

### 11.2 密碼規則

> 密碼長度需要介於 6–100 個字元，註冊時兩次輸入也必須完全一致。密碼可以使用任何字元，請不要在客服對話中提供您的密碼；您可以直接在官網欄位重新輸入或使用正式的密碼恢復流程。

### 11.3 玩家代理推薦碼與代理推廣碼

> 玩家註冊時的代理推薦碼為選填資料，格式需為大寫英數 8 碼。格式正確後，是否有效仍由系統判定；若您不確定推薦碼內容，請向提供代碼的代理或推薦人確認。代理商對外使用的推廣碼則是大寫英數 6 碼，兩者用途不同。

### 11.4 登入失敗

> 請先確認您輸入的是「登入帳號」而不是暱稱，並檢查是否有前後空格、全形字元或輸入法切換的情況。若您忘記密碼，請使用官網的密碼恢復流程；請勿將密碼提供給任何人，包括客服人員。

### 11.5 年齡限制

> 巨亨ONLINE WEB館屬限制級遊戲內容，必須年滿 18 歲才能進入遊玩。客服無法協助繞過年齡確認或提供規避限制的方式。

## 12. 目前系統差異（僅供內部參考）

以下內容不是正式產品說法：

- 目前前端註冊、帳號登入、手機登入、訪客登入與第三方登入仍以 Mock 流程展示，尚未代表正式後端驗證結果。
- 目前前端登入狀態部分保存在瀏覽器 `localStorage`；正式產品應以後端 session/token 與會員資料為準。
- 目前前端會以測試延遲顯示登入或註冊成功；延遲時間不是正式服務承諾。
- 目前前端的手機登入與忘記密碼畫面包含測試驗證碼與測試分支，這些內容不可提供給玩家作為正式操作方式。
- 目前前端輸入框的 `maxlength`、placeholder 或測試錯誤訊息，不得取代正式 API 的驗證規則。
