# 第二章：忘記密碼與帳號恢復

- 章節狀態：草稿，待產品確認
- 版本：0.1
- 建立日期：2026-07-31
- 適用對象：產品營運人員、客服人員
- 對應功能：忘記密碼、手機驗證、第三方登入帳號恢復、未綁定手機帳號協助

## 1. 本章目的

本章說明玩家忘記平台密碼時，如何從登入頁面開始進行帳號識別、手機驗證與新密碼設定；同時說明使用第三方帳號登入、未綁定手機，以及驗證碼失敗時的處理方式。

客服閱讀本章後，應能回答以下問題：

- 忘記密碼要從哪裡申請？
- 為什麼系統會要求綁定手機驗證？
- 忘記密碼流程有哪幾個步驟？
- 使用 LINE、Facebook、Apple 或 Google 登入的玩家，是否需要重設平台密碼？
- 未綁定手機時，玩家應該怎麼做？
- 驗證碼收不到、輸入錯誤或需要重新發送時，客服要如何協助？
- 哪些情況可以請玩家自行重試，哪些情況必須建立客服案件？

## 2. 本章範圍與重要原則

本章描述的是「未登入狀態下的公開密碼恢復流程」，不是登入後在會員設定中主動修改密碼的流程。

忘記密碼流程的正式目標包含四個階段：

1. 識別帳號並判斷可用的恢復方式。
2. 發送驗證碼。
3. 驗證驗證碼並取得一次性的密碼重設權限。
4. 設定新密碼並返回登入。

客服在任何階段都不得要求玩家提供原密碼、簡訊驗證碼、重設 token 或第三方帳號密碼。

## 3. 正式產品規則

### 3.1 密碼重設資格

- 玩家必須先提供符合帳號格式的登入帳號。
- 帳號格式仍依第一章規則：只能使用中文、英文字母與數字，長度為 4–20 個半形字元，中文每字以 2 個半形字元計算。
- 系統必須先識別帳號目前可用的恢復方式，再讓玩家進入對應分支。
- 系統不應顯示完整手機號碼；若使用綁定手機，應以遮罩方式顯示可辨識但不暴露完整號碼的資訊。
- 新密碼至少 6 個字元，且確認密碼必須與新密碼完全一致。
- 正式後端必須重新驗證帳號、驗證碼、重設權限與新密碼，不得只依賴瀏覽器前端檢查。

### 3.2 三種恢復分支

帳號識別後，正式目標流程可能回傳以下三種分支：

| 分支 | 條件 | 玩家處理方式 |
|---|---|---|
| `phone` | 帳號已綁定可用手機 | 使用遮罩手機接收驗證碼，再設定新密碼。 |
| `social` | 帳號是以第三方社群帳號建立或登入 | 使用原本綁定的 LINE、Facebook、Apple 或 Google 登入，不透過平台密碼重設。 |
| `unbound` | 帳號沒有可用的綁定手機，無法自助驗證 | 前往客服中心，由客服依正式身分確認政策協助。 |

分支結果由正式系統判定。客服不得依玩家口述自行把帳號改判為手機、社群或未綁定分支。

### 3.3 驗證碼規則

- 驗證碼為一次性驗證資訊，只能由系統發送至帳號已綁定的驗證管道。
- 驗證碼重新發送按鈕有 60 秒倒數限制；倒數期間不可重複發送。
- 驗證碼的實際有效期限、錯誤嘗試次數、每日發送上限與封鎖規則，尚未在正式契約中完整定義，客服不得自行承諾。
- 客服不得代玩家收取、輸入或確認驗證碼。
- 玩家若把驗證碼提供給任何人，可能造成帳號安全風險；客服應提醒玩家不要傳送驗證碼。

### 3.4 重設權限與安全性

- 驗證碼通過後，系統應發出一次性的密碼重設權限或 `resetToken`。
- `resetToken` 不應被客服要求提供，也不應由玩家在客服對話中傳送。
- 密碼重設成功後，玩家應使用新密碼重新登入。
- 若重設成功後其他裝置仍保持登入，是否全部登出、是否需要重新驗證，須依正式安全政策處理；目前尚未定案。

### 3.5 新密碼規則

- 新密碼至少 6 個字元。
- 新密碼與確認新密碼必須完全一致。
- 目前尚未定義新密碼是否不得與舊密碼相同、是否有最大長度或特殊字元要求。
- 客服不能替玩家指定密碼，也不能在客服系統保存玩家密碼。

## 4. 忘記密碼入口

### 4.1 正常入口

1. 玩家開啟官網登入視窗。
2. 選擇「帳號密碼」登入方式。
3. 點擊「忘記密碼」。
4. 系統進入帳號恢復畫面。

若玩家尚未進入登入視窗，客服可先引導玩家點擊官網的「登入／註冊」入口，再選擇「忘記密碼」。

### 4.2 已知帳號的操作建議

玩家可以先在登入頁輸入帳號，再點擊「忘記密碼」，讓系統帶入該帳號；也可以進入忘記密碼畫面後重新輸入帳號。

若帳號中包含空格、特殊符號或不符合 4–20 個半形字元規則，系統應先要求修正格式，不會進入後續識別流程。

## 5. 正常恢復流程：綁定手機

### 5.1 步驟一：確認帳號

1. 玩家在忘記密碼畫面輸入登入帳號。
2. 玩家按下「下一步」或等效按鈕。
3. 系統檢查帳號格式。
4. 系統識別帳號目前的恢復分支。

客服應提醒玩家：這裡要輸入的是登入帳號，不是暱稱、顯示名稱、推廣碼或手機號碼。

### 5.2 步驟二：確認遮罩手機

若系統判定為 `phone` 分支：

1. 畫面顯示使用綁定手機進行驗證。
2. 畫面只顯示遮罩後的手機資訊。
3. 玩家確認自己可以接收該手機的簡訊。
4. 玩家按下「發送驗證碼」。

若玩家看不出遮罩號碼是否為自己的手機，客服不得直接告知完整綁定手機；應依身分確認政策處理，或請玩家使用客服流程確認帳號持有權。

### 5.3 步驟三：輸入驗證碼

1. 系統向綁定手機發送一次性驗證碼。
2. 畫面進入驗證碼輸入步驟。
3. 玩家輸入收到的驗證碼。
4. 玩家按下「驗證並繼續」。
5. 驗證成功後，系統進入設定新密碼步驟。

驗證碼重發：

- 60 秒倒數結束前，玩家不可再次發送。
- 倒數結束後，玩家可以重新發送驗證碼。
- 重新發送後，應以最新一次發送的有效驗證碼為準；具體失效規則需以正式後端契約為準。

### 5.4 步驟四：設定新密碼

1. 玩家輸入新密碼。
2. 玩家再次輸入確認新密碼。
3. 確認兩次輸入完全一致，且新密碼至少 6 個字元。
4. 玩家按下「確認重設密碼」。
5. 系統驗證重設權限與新密碼。
6. 系統顯示「密碼重設成功」。
7. 玩家返回登入頁，使用新密碼登入。

### 5.5 成功後的處理

密碼重設成功後，客服應請玩家：

- 返回帳號密碼登入頁。
- 輸入原本的登入帳號。
- 輸入剛完成設定的新密碼。
- 不要再使用舊密碼反覆嘗試。

若玩家在重設成功後仍無法登入，應先確認玩家登入的是相同帳號，並記錄重設完成時間與顯示結果，再進行升級判斷。

## 6. 第三方登入帳號恢復

### 6.1 判斷方式

若系統識別出帳號是使用第三方帳號建立或登入，畫面應提示玩家：此帳號沒有平台密碼，請使用原本的第三方服務登入。

目前正式目標支援的第三方服務包含：

- LINE
- Facebook
- Apple
- Google

實際可用服務仍以正式上線版本與產品公告為準。

### 6.2 玩家操作流程

1. 玩家在忘記密碼畫面輸入登入帳號。
2. 系統判定為 `social` 分支。
3. 畫面顯示原本綁定的第三方服務。
4. 玩家按下對應的第三方登入按鈕。
5. 玩家完成第三方服務授權或登入。
6. 系統驗證第三方身份並返回官網。
7. 驗證成功後進入會員功能。

第三方帳號本身的密碼由第三方服務管理，巨亨ONLINE 客服不能替玩家重設，也不能要求玩家提供第三方密碼。

### 6.3 第三方登入失敗

客服先確認：

- 玩家選擇的服務是否與原本綁定的服務相同。
- 是否使用正確的第三方帳號。
- 是否在授權頁取消或拒絕授權。
- 是否出現 callback、重新導向或服務維護錯誤。
- 是否只有特定瀏覽器、裝置或網路會發生。

客服不得請玩家把第三方帳號密碼或授權畫面中的敏感資訊傳送過來。若確認玩家使用正確服務仍無法登入，應建立升級案件。

## 7. 未綁定手機帳號

### 7.1 系統結果

若系統判定帳號為 `unbound` 分支，畫面應說明：帳號尚未綁定手機，目前無法自行完成密碼重設，請前往客服中心。

這個結果代表玩家不能透過本章的手機驗證流程自行恢復密碼，不代表客服可以直接跳過身分確認替玩家改密碼。

### 7.2 玩家操作流程

1. 玩家輸入登入帳號。
2. 系統判定帳號未綁定手機。
3. 玩家點擊「前往客服中心」。
4. 玩家建立或繼續一筆客服案件。
5. 依客服身分確認政策提供必要資料。
6. 客服依案件流程判斷後續處理方式。

### 7.3 客服處理原則

客服應先確認：

- 玩家提供的登入帳號。
- 玩家是否記得原本的登入方式。
- 是否仍能使用任何已綁定的第三方帳號。
- 目前是否仍可存取曾經使用的電子郵件或手機資料。
- 是否有其他可依公司政策進行的身分驗證資料。

客服不得因玩家提供暱稱、頭像、歷史遊戲名稱或自行描述的儲值紀錄，就直接承諾恢復帳號。所有人工協助都必須依正式帳號持有權驗證政策處理。

## 8. 常見例外情境與處理矩陣

| 玩家情況 | 玩家可能看到的結果 | 客服第一步 | 後續處理 |
|---|---|---|---|
| 輸入空白帳號 | 顯示請輸入帳號 | 請玩家填寫登入帳號 | 不接受暱稱或推廣碼替代 |
| 帳號格式錯誤 | 顯示格式或長度錯誤 | 依第一章規則協助修正 | 修正後重新進行帳號識別 |
| 輸入暱稱而非帳號 | 無法識別或顯示查無結果 | 說明暱稱不是登入帳號 | 請玩家回想註冊時使用的帳號 |
| 帳號為手機分支但收不到簡訊 | 未收到驗證碼 | 先確認遮罩手機是否仍可使用、簡訊是否延遲 | 等待或於倒數結束後重發；持續失敗則升級 |
| 驗證碼輸入錯誤 | 顯示驗證失敗 | 請玩家重新確認最新一封簡訊 | 不得要求玩家把驗證碼傳給客服 |
| 驗證碼重發按鈕不可用 | 顯示 60 秒倒數 | 說明倒數期間無法重發 | 倒數結束後再操作，避免連續點擊 |
| 驗證碼逾時或失效 | 驗證失敗或要求重新發送 | 請玩家重新發送最新驗證碼 | 若重發仍失敗，記錄時間後升級 |
| 新密碼少於 6 個字元 | 無法送出或顯示長度不足 | 請設定至少 6 個字元 | 不要求玩家提供密碼內容 |
| 兩次新密碼不一致 | 顯示密碼不一致 | 請重新輸入兩次新密碼 | 確認輸入法與大小寫後重試 |
| 重設成功但仍用舊密碼登入 | 登入失敗 | 請改用剛設定的新密碼 | 若新密碼也失敗，記錄重設時間後升級 |
| 系統判定社群帳號 | 顯示使用原本社群帳號登入 | 引導使用正確第三方服務 | 不進行平台密碼重設 |
| 系統判定未綁手機 | 無法自助重設 | 引導客服中心 | 依身分確認政策建立案件 |
| 重設流程中關閉視窗 | 返回登入頁或流程中斷 | 請重新開始流程 | 不保證原驗證狀態仍有效 |
| 系統維護或功能停用 | 無法進入恢復流程 | 確認是否有正式維護公告 | 不承諾恢復時間，依公告回覆 |
| 多次嘗試後被暫時阻擋 | 顯示安全限制或暫時不可用 | 請玩家停止重複嘗試 | 依正式錯誤訊息與安全政策升級 |

## 9. 驗證碼收不到的處理順序

玩家反映「沒有收到驗證碼」時，客服依下列順序處理：

1. 確認玩家輸入的是登入帳號，不是暱稱。
2. 確認系統顯示的遮罩手機是否仍屬於玩家可使用的手機。
3. 確認玩家是否仍在 60 秒重發倒數期間。
4. 請玩家檢查簡訊是否延遲、訊息匣是否已滿或是否有阻擋簡訊服務。
5. 倒數結束後，只讓玩家重新發送一次並等待。
6. 請玩家以最新收到的驗證碼為準，不要使用舊簡訊中的驗證碼。
7. 若仍未收到，記錄帳號、發送時間、裝置、瀏覽器、遮罩手機尾碼與錯誤畫面，升級查詢。

客服不得要求玩家提供驗證碼內容來確認是否正確，也不得承諾簡訊一定會在特定秒數內送達。

## 10. 客服檢查清單

處理忘記密碼問題時，客服依序確認：

1. 玩家使用的登入帳號。
2. 玩家是否能通過帳號格式檢查。
3. 系統顯示的恢復分支：手機、社群或未綁定手機。
4. 發生問題的恢復步驟：帳號識別、發送驗證碼、驗證碼確認或設定新密碼。
5. 發生時間與時區。
6. 畫面上的完整錯誤訊息。
7. 是否已重新發送驗證碼，以及最後一次發送時間。
8. 玩家是否仍可使用遮罩手機或原本的第三方帳號。
9. 使用裝置、瀏覽器、網路環境與是否能重現。
10. 是否有維護、停權、凍結或功能停用提示。

不得確認或要求：

- 原密碼。
- 新密碼或確認密碼。
- SMS、Email 或其他一次性驗證碼。
- `resetToken` 或其他內部授權資訊。
- LINE、Facebook、Apple、Google 等第三方帳號密碼。

## 11. 升級條件

符合以下任一情況，應建立客服案件或升級給產品、技術或驗證服務團隊：

- 帳號格式符合，但系統無法進入帳號識別流程。
- 系統顯示的恢復分支與玩家實際綁定狀態不符。
- 遮罩手機正確且可用，但多次發送都沒有收到驗證碼。
- 驗證碼在有效操作期間持續被判定錯誤。
- 驗證碼通過後，設定新密碼時一直顯示授權失效。
- 顯示重設成功，但新密碼無法登入。
- 第三方授權成功後，官網無法回到會員狀態。
- 未綁定手機玩家已依政策完成身分資料提供，但案件長時間沒有後續處理。
- 玩家遇到安全鎖定、嘗試次數限制或帳號凍結提示。
- 多位玩家在相同時間回報簡訊、重設或第三方登入異常。
- 目前畫面要求玩家提供測試驗證碼、顯示測試帳號或出現 Mock 文案。

升級資料至少包含：功能名稱、恢復步驟、發生時間、帳號識別資訊、裝置與瀏覽器、錯誤訊息、是否可重現、最後一次發送驗證碼的時間，以及玩家已嘗試的處理方式。不得附上密碼、驗證碼或重設 token。

## 12. 客服回覆範例

### 12.1 忘記密碼入口

> 請先開啟官網的「登入／註冊」視窗，選擇「帳號密碼」，再點擊「忘記密碼」。接著輸入您的登入帳號，系統會依帳號目前的綁定方式引導後續驗證。

### 12.2 手機驗證

> 如果您的帳號已綁定手機，系統會以遮罩方式顯示驗證手機，並將一次性驗證碼發送至該手機。請以最新收到的驗證碼為準，且不要將驗證碼提供給任何人，包括客服人員。

### 12.3 驗證碼沒有收到

> 請先確認畫面上的遮罩手機仍可使用，並確認是否還在重新發送倒數期間。倒數結束後可以重新發送一次，請以最新收到的簡訊為準。若仍未收到，請提供發送時間、裝置、瀏覽器與畫面錯誤訊息，我們會協助進一步確認。

### 12.4 使用第三方帳號登入

> 此帳號是使用第三方帳號建立或登入，沒有獨立的平台密碼，請使用原本綁定的 LINE、Facebook、Apple 或 Google 帳號登入。第三方帳號的密碼需要向對應服務商進行恢復，請不要將第三方密碼提供給客服。

### 12.5 未綁定手機

> 目前此帳號沒有可用的綁定手機，因此無法透過簡訊自行重設密碼。請前往客服中心建立案件，我們會依帳號持有權確認流程協助您；在確認完成前，無法直接承諾恢復帳號或修改密碼。

### 12.6 新密碼規則

> 新密碼至少需要 6 個字元，且兩次輸入必須完全一致。設定完成後，請返回登入頁，使用原本的登入帳號與剛設定的新密碼登入。請不要把密碼傳送給客服。

## 13. 目前系統差異（僅供內部參考）

以下內容不是正式產品說法：

- 目前前端的公開忘記密碼流程是 Mock，尚未接上正式的四支密碼恢復 API。
- 目前前端會依測試帳號名稱模擬不同分支；測試帳號名稱不可提供給玩家作為正式判斷方式。
- 目前前端使用固定的遮罩手機內容作為展示，不能代表玩家實際綁定的手機。
- 目前前端以固定測試驗證碼模擬驗證成功，正式環境應以實際發送的驗證碼為準。
- 目前前端的 60 秒倒數主要是畫面重發限制展示，不能推論為正式驗證碼有效期限。
- 目前前端重設成功資訊與登入驗證資料只存在本次瀏覽器工作階段，正式產品應由後端保存並驗證。
- 目前前端關閉登入視窗或重新整理可能重置恢復流程，不能代表正式產品的 token、驗證碼或案件狀態保存方式。

## 14. 待產品確認

本章正式發布前，仍需確認：

1. 四支公開密碼恢復 API 的正式上線版本與 request/response schema。
2. 帳號識別時是否需要避免暴露「帳號存在／不存在」的資訊。
3. `phone`、`social`、`unbound` 三種分支的正式判定條件與顯示文案。
4. 驗證碼的有效期限、錯誤嘗試次數、重發間隔、每日發送上限與暫時封鎖規則。
5. 驗證碼發送管道是否只有 SMS，或同時支援 Email 等管道。
6. `resetToken` 的有效期限、使用次數與是否在密碼重設後立即失效。
7. 密碼重設成功後是否使其他裝置與既有 session 失效。
8. 新密碼是否不得與舊密碼相同，以及密碼最大長度與允許字元。
9. 未綁定手機帳號的正式身分確認資料、處理時限與可執行的人工協助範圍。
10. 第三方登入失敗、取消授權與第三方帳號不存在時的正式錯誤文案。
11. 帳號凍結、停權、禁用或維護狀態下，是否允許進入密碼恢復流程。
12. 玩家重設密碼後是否自動登入，或一律返回登入頁。
