# 第十二章：好友、聊天、封鎖與檢舉

- 章節狀態：草稿，待產品確認
- 版本：0.1
- 建立日期：2026-08-01
- 適用對象：產品營運人員、客服人員
- 對應功能：世界頻道、私人訊息、客服頻道入口、在線玩家清單、玩家公開資料卡、加好友、移除好友、社交封鎖、解除封鎖、檢舉玩家
- 相關章節：第八章「贈禮功能」、第十三章「客服問題回報與案件處理」、第十四章「代理商常見問題」、第十五章「客服回覆話術與快速查詢表」

## 1. 本章目的

本章說明玩家如何查看其他玩家公開資料、使用世界頻道與私人訊息、管理好友、封鎖或解除封鎖玩家，以及遇到騷擾、詐騙或不當行為時如何提出檢舉。

客服閱讀本章後，應能回答以下問題：

- 世界頻道、私人頻道與客服頻道有什麼差異？
- 玩家如何查看其他玩家的公開資料與最近遊戲？
- 加好友與移除好友會發生什麼事？
- 封鎖玩家後，對方還能不能私訊、送禮或查看資料？
- 解除封鎖後，好友關係會不會自動恢復？
- 如何檢舉不當言論、騷擾、疑似詐騙或冒用身分？
- 檢舉後是否一定會處分對方？客服可以透露處理結果嗎？

本章的核心原則是：

> 社交功能只能處理玩家之間的互動，不會授予任何人查看他人密碼、驗證碼、付款資料或完整資產紀錄的權限。封鎖是玩家安全措施；檢舉是提供給平台審核的案件，不代表檢舉人可以直接決定處分結果。

## 2. 功能入口與頻道區分

### 2.1 三個頻道

| 頻道 | 主要用途 | 玩家可見範圍 | 主要注意事項 |
|---|---|---|---|
| 世界頻道 | 公開聊天、查看在線玩家 | 同一公開頻道的玩家 | 不要公開個資、付款資料或要求私下匯款 |
| 私人頻道 | 與特定玩家一對一對話 | 對話雙方 | 官網目前沒有私訊附件直接送點功能，贈禮要走第八章 |
| 客服頻道 | 建立與追蹤客服提問 | 玩家與客服 | 工單有同時進行中上限，詳見第十三章 |

頻道可透過聊天頁分頁或 URL query 進入。玩家由玩家卡按下私訊、贈禮或檢舉時，系統會導向相應功能；贈禮與客服提問不是聊天訊息本身。

### 2.2 登入條件

- 查看公開內容是否需要登入，依正式頁面設定。
- 發送世界訊息、建立私人對話、加好友、封鎖、檢舉與客服提問需登入會員。
- 未登入玩家按下受限制操作時，系統應先引導登入。
- 登入後重新查詢玩家清單與互動權限，不要沿用登入前的公開資料快取。

## 3. 玩家公開資料卡

### 3.1 可公開查看的資料

玩家卡目前可包含：

- 玩家識別碼或公開帳號。
- 暱稱與頭像。
- VIP 等級或公開會員標示。
- 等級。
- 在線、遊戲中或閒置狀態（若正式版本公開）。
- 個人簡介。
- 最近遊戲（若正式隱私規則允許）。
- 是否為好友。

玩家卡不應顯示：

- 密碼、手機完整號碼、驗證碼或第三方登入憑證。
- 儲值金幣、銀幣、活動幣、保險箱或其他資產餘額。
- 完整付款卡號、訂單付款資料或客服案件內容。
- 未經玩家同意公開的個人資料。

### 3.2 查看玩家卡流程

1. 玩家進入世界頻道或在線玩家清單。
2. 點擊一位玩家的頭像、名稱或訊息。
3. 系統載入玩家公開資料卡。
4. 玩家查看公開資訊與目前可用操作。
5. 玩家可選擇私訊、加好友、封鎖、檢舉或進入贈禮流程。
6. 關閉玩家卡返回原頻道。

如果玩家已被封鎖，公開資料與互動按鈕可能被隱藏或停用。客服不可要求前端繞過封鎖查看對方資料。

### 3.3 最近遊戲資料

目前規格將「最近遊戲」視為玩家公開資料的一部分，但是否公開、是否提供隱私開關尚未完成決策。正式版本若公開，應只顯示遊戲名稱或其他已定義的摘要，不應公開下注金額、輸贏、局號或個人遊戲紀錄。

「最近遊戲」與玩家自己的遊戲投注明細不同：

- 最近遊戲：可能出現在玩家卡上的公開遊戲清單。
- 我的最近遊玩：玩家自己的大廳歷史入口。
- 遊戲投注明細：玩家自己的正式投注與結算紀錄。

## 4. 世界頻道操作

### 4.1 查看與發送訊息

1. 玩家登入並進入聊天頁。
2. 選擇「世界頻道」。
3. 查看目前公開訊息與在線玩家。
4. 輸入訊息內容。
5. 確認內容不包含密碼、驗證碼、付款資料、個資或私下收款要求。
6. 按下送出。
7. 系統檢查登入狀態、帳號是否被禁言、內容是否符合訊息規則與發送頻率。
8. 成功後訊息顯示在頻道中。

### 4.2 世界頻道的安全規則

- 不要在公開頻道貼出手機、Email、身分證、銀行帳號或完整訂單資訊。
- 不要散布保證獲利、代儲、代打、私下換現金或要求玩家加私人帳號的訊息。
- 不要冒充官方客服、代理商或平台人員。
- 不要以刷屏、重複貼文、騷擾或辱罵方式影響其他玩家。
- 平台可能依正式規則進行敏感詞替換、阻擋、監控、限速或禁言。

目前敏感詞動作與發言頻率上限仍需正式契約確認，客服不可自行告訴玩家一個未公布的固定字數或頻率數值。

## 5. 私人訊息操作

### 5.1 開始私人對話

1. 玩家從玩家卡按下「私訊」，或從私人頻道選擇對話。
2. 系統建立新對話或開啟既有對話。
3. 玩家查看對方公開名稱與頭像。
4. 輸入訊息並送出。
5. 系統檢查對方是否已封鎖、帳號是否可互動及訊息是否符合規則。
6. 成功後顯示在私人對話中。

### 5.2 私訊與贈禮分開

官網私人訊息目前沒有直接附加遊戲點數或直接轉帳的附件選單。若玩家想送禮：

1. 從玩家卡選擇贈禮。
2. 系統導向保險箱／贈禮入口，帶入收禮者。
3. 依第八章建立雙向確認申請。

客服不可教導玩家在私訊中直接傳送金額、驗證碼或付款資訊，也不可把聊天訊息當成贈禮完成證明。

### 5.3 對話中的封鎖結果

若任一方封鎖對方，私人訊息可能停止發送，既有對話可能保留為歷史但不再接受新訊息。玩家看到對話仍存在，不代表可以繞過封鎖繼續聯絡。

## 6. 好友管理

### 6.1 加好友

1. 玩家打開對方玩家卡。
2. 確認對方帳號與暱稱。
3. 按下「加好友」。
4. 系統檢查是否已是好友、是否被封鎖、帳號是否存在及好友限制。
5. 成功後更新好友狀態。

正式版本是否需要對方接受好友邀請尚未完全拍板。目前前端是單方面加入好友的流程；若產品改為雙向同意，應以「待接受／已接受／已拒絕」等狀態取代立即成為好友。客服不可自行承諾對方一定已收到或接受好友邀請。

### 6.2 移除好友

1. 玩家開啟好友列表或對方玩家卡。
2. 選擇「移除好友」。
3. 確認移除。
4. 系統移除好友關係。
5. 私人對話是否保留，依聊天歷史規則處理；移除好友不必然等於刪除對話。

### 6.3 好友與封鎖的關係

- 封鎖玩家時，系統會同時移除好友關係。
- 解除封鎖後，不會自動恢復原好友關係。
- 若要重新成為好友，須重新依正式好友流程操作。
- 封鎖不代表對方的帳號被平台停權；它只代表目前玩家不想與對方互動。

## 7. 封鎖與解除封鎖

### 7.1 封鎖玩家

1. 從玩家卡選擇「封鎖」或「加入黑名單」。
2. 確認封鎖對象與提醒內容。
3. 按下確認。
4. 系統將玩家加入社交封鎖清單。
5. 系統同步移除好友關係。
6. 返回聊天或玩家清單時，對方的互動功能依封鎖規則停用。

封鎖後可能出現：

- 無法查看對方玩家卡。
- 無法傳送私人訊息。
- 無法對對方建立贈禮申請。
- 對方無法透過一般社交入口與玩家互動。
- 已有對話仍留在列表，但顯示不可互動。

實際可見範圍依正式社交權限規則為準；客服不應承諾封鎖會讓玩家在所有頁面完全消失。

### 7.2 解除封鎖

1. 進入設定中的「黑名單管理」或社交封鎖清單。
2. 找到被封鎖玩家。
3. 按下「解除封鎖」。
4. 確認解除。
5. 系統從封鎖清單移除對方。
6. 若要恢復好友關係，需重新發起好友流程。

解除封鎖不會自動恢復好友，也不會恢復已刪除的聊天訊息。

## 8. 檢舉玩家流程

### 8.1 何時應檢舉

玩家可以檢舉：

- 不當言論或辱罵。
- 騷擾、威脅或持續打擾。
- 疑似詐騙、私下收款或保證獲利。
- 冒用官方、客服、代理商或其他玩家身分。
- 其他違反平台規範的行為。

如果玩家只是不想再收到訊息，可先封鎖；若同時涉及詐騙、威脅、個資外洩或大規模影響其他玩家，應同時檢舉並提供證據。

### 8.2 從玩家卡檢舉

1. 開啟對方玩家卡。
2. 按下「檢舉」。
3. 選擇最符合的檢舉原因。
4. 填寫補充說明，例如發生時間、頻道、對話內容或交易識別資訊。
5. 確認內容真實且不包含不必要的個資。
6. 按下「送出檢舉」。
7. 系統建立檢舉案件或客服提問。
8. 玩家取得案件識別資訊，並可依第十三章查看後續狀態。

### 8.3 檢舉資料建議

請玩家提供：

- 被檢舉玩家公開名稱或玩家 ID。
- 發生時間與時區。
- 世界頻道、私人頻道或其他功能位置。
- 原始訊息、截圖或可重現步驟。
- 是否有付款、贈禮或外部聯絡要求。
- 是否已封鎖對方。

請玩家不要提供：

- 自己或他人的密碼與驗證碼。
- 完整信用卡、銀行帳號或支付安全碼。
- 與案件無關的完整身分證件影本。

### 8.4 檢舉後處理

- 檢舉提交成功只代表案件已建立，不代表對方已被處分。
- 平台會依內容、證據、歷史紀錄與正式社群規範審查。
- 客服不得透露其他玩家的內部處分、個人資料或審核細節。
- 玩家可以查看自己的案件狀態或等待平台通知；不得透過重複檢舉加速處理。
- 若涉及立即人身安全、重大詐騙或外部犯罪，應提醒玩家保留證據並依需要向相關機關求助。

## 9. 常見情境與處理矩陣

| 玩家情況 | 玩家可能看到的結果 | 客服第一步 | 後續處理 |
|---|---|---|---|
| 看不到玩家卡 | 對方已封鎖、資料不可公開或載入失敗 | 確認是否在自己的封鎖清單 | 不協助繞過權限查詢 |
| 不能私訊對方 | 被封鎖、對方停用互動或帳號狀態異常 | 確認對話與社交狀態 | 不承諾強制開放私訊 |
| 封鎖後仍看到舊對話 | 歷史對話保留但不能發送 | 說明歷史與新互動分開 | 依正式保存規則處理 |
| 解除封鎖後不是好友 | 封鎖時已移除好友 | 說明解除不自動恢復 | 重新發起好友流程 |
| 加好友後對方沒出現 | 可能是邀請待接受、同步延遲或目前單向 Mock | 查好友狀態與玩家 ID | 依正式好友模型處理 |
| 世界訊息送不出去 | 禁言、頻率限制、內容被阻擋或網路錯誤 | 記錄頻道、時間與錯誤 | 不反覆刷送，必要時升級 |
| 被別人騷擾 | 私訊或公開頻道持續發送 | 先封鎖並保留證據 | 另送檢舉案件 |
| 收到代儲／私下換現金訊息 | 對方要求私下付款 | 不付款、不提供資料 | 截圖、封鎖並檢舉 |
| 檢舉送不出去 | 進行中客服案件已達上限或欄位不足 | 查案件數與檢舉內容 | 依第十三章處理，不重複建立 |
| 檢舉後想撤回 | 案件已建立 | 查案件狀態與撤回規則 | 未有正式撤回功能前不承諾撤回 |
| 玩家要求知道對方是否被處分 | 希望查看內部結果 | 說明個案處理受隱私限制 | 可提供自己的案件狀態，不透露他人資料 |
| 最近遊戲資料不想公開 | 玩家卡顯示最近遊戲 | 查正式隱私設定 | 隱私開關仍待產品確認 |

## 10. 客服檢查清單

1. 玩家帳號與身分驗證。
2. 頻道或功能：世界、私人、玩家卡、設定或客服案件。
3. 互動對象的公開玩家 ID，不只提供暱稱。
4. 操作時間、時區與是否可重現。
5. 是否已封鎖、解除封鎖、加好友或移除好友。
6. 訊息內容、截圖、頻道與錯誤提示。
7. 檢舉原因、補充說明與案件編號。
8. 是否涉及付款、贈禮、外部連結或疑似詐騙。
9. 是否已有進行中的客服提問。
10. 是否包含不應收集的密碼、驗證碼或付款敏感資料。

## 11. 客服可直接處理與升級條件

### 11.1 可直接處理

- 引導玩家封鎖或解除封鎖。
- 說明封鎖會移除好友，解除後不會自動恢復好友。
- 引導從玩家卡開啟私訊、好友或檢舉。
- 說明玩家公開資料與私人帳務資料的差異。
- 協助整理檢舉時間、頻道、玩家 ID 與證據。
- 提醒玩家防詐騙與不要提供敏感資訊。

### 11.2 必須升級

- 封鎖後仍可收到訊息、贈禮或查看不應顯示的資料。
- 解除封鎖後狀態、好友關係與對話權限不一致。
- 訊息被重複發送、刪除後仍顯示或出現他人訊息錯置。
- 被禁言帳號仍能發送訊息，或未被禁言卻無法發送。
- 檢舉案件建立成功但沒有案件編號或無法追蹤。
- 疑似詐騙、冒用官方或重大安全事件。
- 公開玩家資料含有不應公開的資產、聯絡或個資。

### 11.3 禁止事項

- 不得替玩家揭露其他玩家的私人資料或內部處分結果。
- 不得承諾檢舉一定成立、一定封號或一定在固定時間處理完成。
- 不得要求玩家公開貼出密碼、驗證碼、卡號或銀行資料。
- 不得教導玩家繞過封鎖、頻率限制、禁言或檢舉流程。
- 不得把玩家社交封鎖與營運後台 IP／裝置風控封鎖混為一談。

## 12. 客服回覆範例

### 玩家詢問「封鎖後對方還能不能送禮？」

> 封鎖會停止或限制與對方的社交互動，並同時移除好友關係。贈禮是否被系統擋下，仍會依收禮資格與正式封鎖規則判定；若您仍收到贈禮申請或通知，請提供玩家 ID 與時間，我們會查詢。

### 玩家詢問「解除封鎖後為什麼不是好友？」

> 封鎖時會同步移除好友，解除封鎖只會移除封鎖狀態，不會自動恢復好友關係。若要重新成為好友，請重新從玩家卡發起好友操作。

### 玩家詢問「檢舉後可以知道對方被怎麼處理嗎？」

> 檢舉會交由平台依規則與證據審核。為保護其他玩家的隱私，我們不能提供對方的內部處分或個人資料；您可以提供案件編號查詢自己的案件狀態。

### 玩家詢問「有人叫我私下匯款換金幣」

> 請不要匯款、不要提供密碼或驗證碼，也不要點擊對方提供的可疑連結。請保留聊天截圖、玩家 ID、發生時間與連結資訊，先封鎖對方並送出檢舉，我們會協助轉交安全審核。

## 13. 目前系統差異

以下只供內部理解前端 Mock，不可取代正式規則：

- 目前好友、封鎖與聊天資料主要存於本次瀏覽工作階段，重新整理可能回到測試狀態；正式版本應由後端保存並跨裝置同步。
- 目前加好友是單方面立即加入，是否需要雙向同意尚待確認。
- 目前世界訊息與私人對話沒有完整 WebSocket、分頁、server timestamp 與 player ID 資料；正式版本需由即時服務與後端資料提供。
- 目前前端可能用玩家名稱反查資料，同名玩家會有辨識風險；正式版本應以 `player_id` 為主鍵。
- 目前敏感詞替換／阻擋／監控與發言頻率限制尚未接入前台。
- 目前檢舉原因是固定中文文字，正式版本應改為後端可統計的 reason code。
- 目前檢舉會建立客服提問；是否改為獨立 `/reports` 案件仍待正式契約確認。
- 目前玩家最近遊戲資料可出現在公開資料卡，但是否提供隱私開關尚未決定。

## 14. 待產品確認

- 好友是否採直接加入、邀請／接受，或雙向確認。
- 好友邀請的有效期限、拒絕與取消規則。
- 社交封鎖後對玩家卡、世界頻道、私人訊息、贈禮與好友列表的完整影響範圍。
- 解除封鎖後是否允許直接重新私訊，以及歷史對話保留期限。
- 玩家最近遊戲是否公開、公開欄位與隱私設定。
- 世界／私人訊息的字數上限、敏感詞規則與發言頻率限制。
- 訊息刪除、撤回、編輯與檢舉中的原文保存規則。
- 檢舉是獨立案件或客服工單，以及案件狀態與回覆方式。
- 檢舉理由 code、證據保存期限與重大安全事件的處理時限。
