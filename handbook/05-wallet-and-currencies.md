# 第五章：錢包與遊戲幣別

- 章節狀態：草稿，待產品確認
- 版本：0.1
- 建立日期：2026-08-01
- 適用對象：產品營運人員、客服人員
- 對應功能：錢包餘額、遊戲幣別、儲值幣、活動幣、銅幣、獎勵卡、交易紀錄
- 相關章節：第三章「遊戲大廳與遊戲進行方式」、第四章「試玩模式與真錢模式」、第六章「儲值與付款」、第七章「金庫、幣別兌換與資金轉移」、第八章「贈禮功能」

## 1. 本章目的

本章定義官網的錢包架構與各種遊戲幣別，讓營運與客服能正確判斷玩家看到的餘額、可使用的遊戲幣別，以及不同資產在儲值、遊戲、兌換、保險箱與贈禮流程中的限制。

客服閱讀本章後，應能回答以下問題：

- 「錢包」和「遊戲錢包」是不是兩個不同帳戶？
- 為什麼遊戲啟動前要選擇金幣、銀幣或活動幣？
- 金幣、銀幣、銅幣的價值和用途有什麼不同？
- 活動金幣、活動銀幣為什麼會有流水、上限與期限？
- 保險箱餘額能不能直接拿來遊戲？
- 金幣和銀幣如何換算？
- 玩家看到的餘額與遊戲中的餘額不一致時，要先查什麼？

本章的核心原則是：

> 平台採單一錢包架構。玩家沒有獨立的遊戲子錢包；遊戲使用的是同一份平台資產中，依「幣別 × 來源」區分的可用 bucket。保險箱金幣是獨立的保管位置，不可直接遊玩；銅幣是無價值試玩幣，不是現金或正式可兌換資產。

## 2. 重要名詞

| 名詞 | 本手冊中的定義 |
|---|---|
| 錢包 | 玩家在平台上的資產總管理機制，包含可遊玩的幣別來源與保險箱資產。 |
| Bucket | 錢包中可獨立計算餘額、來源與限制的資產區塊。正式模型依幣別與來源區分。 |
| 儲值幣 | 玩家透過正式儲值或正式兌換取得的儲值金幣、儲值銀幣。 |
| 活動幣 | 以獎勵卡為載體派發的活動金幣或活動銀幣，可能有流水、轉換上限與有效期限。 |
| 銅幣 | 無現金價值的試玩幣，只供試玩用途。 |
| 保險箱 | 用來暫存金幣的內部資產位置，可與主錢包互相存取，但不能直接進入遊戲。 |
| 遊戲錢包選項 | 遊戲啟動前讓玩家選擇本次扣款來源的介面選項，不代表建立新的子錢包。 |
| 獎勵卡 | 活動金幣或活動銀幣的正式載體，內含幣別、數量、流水目標、轉換上限、期限與來源等參數。 |

## 3. 正式錢包架構

### 3.1 單一錢包，不設遊戲子錢包

正式產品採單一錢包架構：

- 玩家只有一份平台錢包資產，不會因為進入不同遊戲而建立新的遊戲子錢包。
- 遊戲下注與派彩會直接與平台錢包服務交換資料。
- 玩家不需要先執行「轉入遊戲錢包」才能開始遊戲。
- 玩家離開遊戲，也不代表需要執行「轉出遊戲錢包」。
- 遊戲啟動時選擇的 wallet，只是指定本次遊戲從哪個資產來源扣款，不是資金轉帳。
- 遊戲中的正式下注、派彩與餘額變動，應以正式遊戲與錢包交易紀錄為準。

因此，客服不可使用「遊戲錢包裡還有多少」作為固定說法。較準確的說法是：「請確認您在遊戲啟動時選擇的幣別來源，以及該來源目前的可用餘額。」

### 3.2 正式 bucket 全集

| Bucket | 正式名稱 | 來源 | 可否遊玩 | 主要限制 |
|---|---|---|---|---|
| `gold.stored` | 儲值金幣 | 儲值或正式資產流程 | 依遊戲支援與帳號資格 | 依可用餘額、遊戲限額與平台規則 |
| `gold.activity` | 活動金幣 | 獎勵卡 | 依遊戲支援與獎勵卡資格 | 可能有流水、轉換上限與到期日 |
| `silver.stored` | 儲值銀幣 | 儲值或金銀兌換 | 依遊戲支援與帳號資格 | 依可用餘額、遊戲限額與平台規則 |
| `silver.activity` | 活動銀幣 | 獎勵卡 | 依遊戲支援與獎勵卡資格 | 可能有流水、轉換上限與到期日 |
| `bronze` | 銅幣 | 試玩用途 | 僅限試玩 | 無現金價值，不可兌換或提款 |
| `vault.gold` | 保險箱金幣 | 玩家存入保險箱 | 不可直接遊玩 | 必須先取回主錢包，才可能依規則使用 |

客服處理餘額問題時，至少要分辨「幣別」與「來源」兩個維度。例如「金幣 5,000」仍不足以判斷是儲值金幣、活動金幣，還是保險箱金幣。

### 3.3 儲值幣與活動幣的差異

儲值金幣、儲值銀幣與活動金幣、活動銀幣都可能出現在真錢模式的可選來源中，但它們不是同一種資產：

- 儲值幣主要代表玩家透過正式儲值或正式兌換取得的資產。
- 活動幣是獎勵資產，必須依所屬獎勵卡規則使用。
- 活動幣可能只能在指定遊戲、指定時間或指定條件下使用。
- 活動幣的餘額不應直接等同可提領現金。
- 活動幣不能脫離獎勵卡的流水、轉換上限與期限單獨解釋。

> 規格確認注記（2026-08-03，部分確認）
>
> 已取得的規格資訊：活動金幣與活動銀幣可使用的遊戲範圍統一由後台設定；玩家點選遊戲後，幣別選擇會依該遊戲的可用範圍進行篩選。
>
> 尚待確認：
> - 同時有多個可用錢包來源時，正式扣款優先順序為何。
> - 不符合遊戲範圍時，錢包選項是隱藏、停用，還是顯示不可用原因。
> - 後台設定更新後，前端篩選何時生效，以及是否需要重新整理或重新進入遊戲。

## 4. 幣別價值與整數規則

### 4.1 正式比率

目前已確認的價值比率為：

> NT$ 1：金幣 1：銀幣 100

這代表在正式金銀兌換規則下：

- 1 金幣可兌換 100 銀幣。
- 100 銀幣可兌換 1 金幣。
- 銅幣不適用此比率。
- 試玩結果不得套用此比率換成金幣、銀幣或現金。

> 規格確認注記（2026-08-03，核心規則已確認）
>
> 已取得的規格資訊：金幣與銀幣的兌換只限儲值幣，活動金幣、活動銀幣與銅幣不得參與金銀兌換。
>
> 尚待確認：保險箱中的儲值金幣是否可直接參與兌換，或必須先取回主錢包；以及被限制、凍結或不可用的儲值幣是否適用相同規則。

### 4.2 金額一律使用整數

- 金幣、銀幣、銅幣與相關操作金額以整數處理。
- 玩家輸入小數時，依正式規則無條件捨去小數部分。
- 捨去後小於或等於 0 的金額不得送出。
- 前台顯示與後端計算不可使用不同的四捨五入方式。
- 客服不得自行將玩家的餘額四捨五入後當成正式結果。

例如玩家輸入 100.9 金幣，系統應先以 100 金幣判斷；若該操作需要完整金額或輸入不符合畫面規則，則應依正式錯誤訊息拒絕，而不是由客服自行補差額。

## 5. 活動幣與獎勵卡規則

### 5.1 所有活動幣都必須有獎勵卡

正式規則為：所有活動金幣與活動銀幣的派發，都以獎勵卡作為載體。常見來源包括：

- 每日簽到里程碑獎勵。
- 營運補償或推廣活動派發。
- 其他經正式產品規則定義的活動來源。

不存在「沒有獎勵卡、但客服可以直接說明為活動幣」的正式資產。玩家詢問活動餘額時，應先找到對應獎勵卡，再確認卡片的幣別、餘額與規則。

### 5.2 獎勵卡應包含的資訊

每張獎勵卡應能辨識以下資訊：

- 幣別：活動金幣或活動銀幣。
- 卡片金額或目前餘額。
- 流水目標與目前進度。
- 可轉換上限。
- 到期時間。
- 發放來源，例如簽到里程碑或營運派發。
- 卡片狀態，例如未啟用、使用中、暫停、已轉換或已過期。

同一幣別同時只能有一張 active 卡；獎勵卡總數目前暫定不設上限。客服不可用目前畫面上看到的固定卡片數量，推論玩家只能有幾張活動卡。

### 5.3 過期與回收

- 到期後，獎勵卡自動失效。
- 卡內剩餘餘額無法再使用，也無法取出。
- 過期資產視為沒收，正式資產流水對應 `WIPE`／獎勵清除類型。
- 若過期前該卡是啟用中的活動幣來源，玩家可用活動餘額可能會突然減少。
- 前台應顯示過期原因或卡片狀態，客服應以獎勵卡明細與正式流水說明，不可直接承諾補回。
- 過期判定由後端負責，前台不應自行以本機時間改寫正式結果。

有效流水的細節、哪些遊戲或交易可以累積流水，以及轉換完成後的餘額處理，仍須依獎勵卡正式契約與產品規則確認。

> 規格確認注記（2026-08-03，轉換方向已確認）
>
> 已取得的規格資訊：獎勵卡完成流水後，活動金幣自動轉換為儲值金幣；活動銀幣自動轉換為儲值銀幣。
>
> 尚待確認：轉換觸發時點、轉換金額是全部餘額或符合條件的部分餘額、獎勵卡結案狀態、正式流水類型（例如 `BONUS_CONVERT`）與玩家通知方式。

## 6. 查看錢包與判讀餘額

### 6.1 玩家查看餘額的標準流程

1. 玩家登入官網。
2. 從會員中心、遊戲大廳或錢包入口開啟錢包資訊。
3. 查看儲值金幣、儲值銀幣、活動金幣、活動銀幣與銅幣等可見項目。
4. 若要查看保管中的資產，另外查看保險箱金幣。
5. 若要追查異動，開啟交易紀錄並依日期、類型或狀態篩選。
6. 進入遊戲前，重新確認本次選擇的幣別來源與可用餘額。

### 6.2 可用餘額與總餘額不可混用

玩家看到的數字可能因以下原因不同：

- 資產位於保險箱，不是主錢包可用餘額。
- 活動幣被獎勵卡的期限、流水或遊戲資格限制。
- 遊戲啟動時選擇的是另一個 bucket。
- 遊戲中的下注或派彩尚未同步回前台顯示。
- 錢包餘額更新本身應即時完成並同步至其他裝置；若儲值訂單、外部支付或遊戲供應商交易另有處理狀態，應依該流程的正式定義判讀，不應把它泛稱為錢包餘額「進行中」。
- 活動卡已過期，餘額依正式回收規則被清除。

> 規格確認注記（2026-08-03，部分確認）
>
> 已取得的規格資訊：錢包餘額更新為即時同步，玩家在不同裝置上應看到一致的正式餘額；正常錢包餘額更新不使用「進行中」作為狀態。
>
> 尚待確認：前台顯示文案、重新查詢或重新整理的引導方式，以及儲值訂單、外部支付、遊戲局結算等個別流程是否存在獨立的處理中狀態。

若不同裝置或不同頁面顯示不一致，應視為資料異常處理，記錄時間、幣別、bucket、交易編號或遊戲局號後升級查帳，不應以同步延遲作為一般性結論。

客服回答前，應先問清楚玩家指的是哪一種幣別、哪一個來源、哪個頁面的數字，以及發生時間。

## 7. 遊戲啟動時選擇錢包來源

### 7.1 標準流程

1. 玩家在遊戲大廳選擇真錢模式。
2. 系統列出該遊戲可使用的幣別來源。
3. 玩家查看每個選項的幣別、來源、可用餘額與停用原因。
4. 玩家選擇一個可用的錢包來源。
5. 系統確認遊戲支援幣別、帳號資格、餘額與遊戲狀態。
6. 確認成功後取得遊戲啟動資訊。
7. 遊戲中的下注從玩家選定的 bucket 扣除，派彩依正式結算規則回到對應資產。

### 7.2 選項停用時的判斷

某個錢包選項可能因以下原因停用：

- 遊戲不支援該幣別。
- 該來源目前沒有可用餘額。
- 活動卡尚未達到可使用條件。
- 活動卡已暫停、已轉換或已過期。
- 玩家帳號資格或 VIP 條件不符合。
- 遊戲目前維護或不接受新的遊戲 session。

畫面若提供停用原因，客服應以該原因為第一判斷依據；若沒有原因或原因與正式資料不一致，需收集遊戲名稱、帳號、時間與畫面截圖後升級。

## 8. 交易紀錄與資產異動

錢包交易紀錄用來追蹤資產的來源與去向。正式交易類型至少包含下列概念：

| 正式概念 | 說明 |
|---|---|
| `DEPOSIT` | 儲值訂單完成後的資產入帳。 |
| `BET` / `WIN` | 遊戲下注與派彩事件。 |
| `VAULT_IN` / `VAULT_OUT` | 主錢包與保險箱之間的內部存入／取回。 |
| `EXCHANGE` | 金幣與銀幣的正式兌換。 |
| `P2P_IN` / `P2P_OUT` | 贈禮接收／送出相關的資產流水。 |
| `REWARD_CLAIM` | 領取活動或獎勵。 |
| `BONUS_CONVERT` | 獎勵卡依規則完成轉換。 |
| `BONUS_WIPE` | 獎勵卡過期或依正式規則清除資產。 |

官網目前部分畫面可能把多種正式方向合併顯示為「vault」或「gift」。客服若需要查帳，不應只依畫面簡稱判斷，應以交易方向、交易編號、狀態與資產 bucket 交叉確認。

## 9. 常見情境與處理矩陣

| 玩家情況 | 玩家可能看到的結果 | 客服第一步 | 後續處理 |
|---|---|---|---|
| 不知道金幣與銀幣差異 | 只看到兩個數字，不知道哪個能用 | 先確認幣別與來源 | 依「NT$1＝金1＝銀100」及遊戲支援說明 |
| 把銅幣當成正式資產 | 詢問如何儲值、兌換或提款 | 說明銅幣是無價值試玩幣 | 不建立兌換或提款承諾 |
| 保險箱有餘額但遊戲不能用 | 遊戲選單顯示餘額不足 | 確認資產是否位於 `vault.gold` | 引導先取回主錢包，詳見第七章 |
| 活動幣看不到 | Header 沒有顯示或只在獎勵卡頁看到 | 確認是否有對應獎勵卡 | 依 F-05／獎勵卡明細說明，不自行補發 |
| 活動幣突然減少 | 獎勵卡到期或狀態改變 | 查卡片期限、狀態與流水 | 若正式規則符合，說明回收；否則升級查帳 |
| 真錢遊戲沒有可用選項 | 選項停用或無法啟動 | 確認遊戲支援幣別與可用餘額 | 查帳號資格、維護狀態與正式回應 |
| 玩家要求把銀幣直接換台幣 | 詢問現金提款 | 說明平台不提供外部提款或現金兌換 | 只能提供正式儲值、兌換與帳務說明 |
| 餘額與遊戲中不同 | 頁面更新前後數字不一樣 | 記錄時間、遊戲、局號與 bucket | 重新查正式錢包與遊戲紀錄，不直接改帳 |
| 交易紀錄只顯示簡稱 | 不知道是存入還是取回 | 先看交易方向與編號 | 依正式 `VAULT_IN/OUT` 或其他類型判斷 |
| 玩家輸入小數 | 送出後數值被截斷或被拒絕 | 確認實際送出的整數金額 | 依正式整數規則，不自行四捨五入補差額 |
| 活動卡已過期要求恢復 | 餘額已無法使用 | 確認卡片到期時間與正式 WIPE 記錄 | 只有資料不一致時才升級，不承諾恢復 |

## 10. 客服檢查清單

處理錢包或幣別問題時，依序確認：

1. 玩家帳號與身分驗證是否完成。
2. 問題發生的日期、時間與時區。
3. 玩家所在頁面：會員中心、遊戲啟動視窗、遊戲畫面或交易紀錄。
4. 幣別：金幣、銀幣或銅幣。
5. 來源：儲值、活動卡或保險箱。
6. 遊戲名稱、供應商與是否為試玩或真錢模式。
7. 是否有下注、派彩、兌換、存入或取回等操作。

## 11. 客服可直接處理與升級條件

### 11.1 可直接處理

- 說明金幣、銀幣、銅幣與活動幣的基本差異。
- 說明保險箱不是可直接遊玩的錢包來源。
- 引導玩家確認遊戲啟動時選擇的 wallet bucket。
- 說明金銀換算比率與整數規則。
- 引導玩家查看獎勵卡期限、流水與狀態。
- 說明平台不提供外部提款或現金兌換。

### 11.2 必須升級

- 正式錢包餘額、交易流水與遊戲畫面不一致。
- 已完成的下注或派彩沒有對應正式紀錄。
- 錢包選項的停用原因與帳號、遊戲規則不一致。
- 活動卡未到期卻被標示為過期或出現不明 `WIPE`。
- 同一交易重複扣款或同一派彩重複入帳。
- 金額計算、兌換結果或整數捨去與正式規則不一致。
- 玩家反映跨裝置看到不同的正式餘額。

### 11.3 禁止事項

- 不得要求玩家提供密碼、驗證碼或支付卡安全碼。
- 不得直接承諾人工增加、恢復或刪除錢包資產。
- 不得將試玩銅幣說成現金、儲值幣或可提款點數。
- 不得把保險箱取回說成外部提款。
- 不得把目前 Mock 的初始餘額、活動卡數量或畫面文字當成正式規則。

## 12. 客服回覆範例

### 玩家詢問「錢包裡的金幣可以直接玩所有遊戲嗎？」

> 不一定。每款遊戲支援的幣別、帳號資格與可用來源可能不同，請在進入真錢模式前查看遊戲啟動視窗的錢包選項與停用原因。保險箱金幣不能直接遊戲，需先取回主錢包。

### 玩家詢問「銅幣可以換成銀幣嗎？」

> 銅幣是平台提供的試玩幣，不具有現金或正式兌換價值，因此不能換成銀幣、金幣或現金。試玩結果也不會轉入正式錢包。

### 玩家詢問「我的活動金幣為什麼突然不見？」

> 活動金幣是獎勵卡資產，會依該卡的流水、使用狀態與有效期限計算。請提供獎勵卡名稱或編號、發生時間與畫面截圖，我們會先確認卡片是否已到期、完成轉換或依規則被回收。

### 玩家詢問「平台能不能把餘額領回台幣？」

> 目前平台提供的是正式儲值與平台內遊戲幣別管理，不提供外部提款或現金兌換。保險箱的「取回」是將金幣從保險箱移回主錢包，不是提領到銀行或現金帳戶。

## 13. 目前系統差異

以下內容只供內部理解目前前端 Mock，不可取代正式規則：

- 目前官網以 `balance`、`silverBalance`、`bronzeBalance`、`vaultBalance` 等扁平欄位模擬狀態，尚未完整表達活動金幣與活動銀幣的正式 bucket。
- 目前前端刷新頁面後，財務狀態會重置為測試資料；這不代表正式產品會重置玩家餘額。
- 目前部分畫面使用固定測試餘額或固定獎勵卡，正式版本應由後端資料提供。
- 目前活動卡的流水累積與到期邏輯仍屬原型，正式過期判定與 `WIPE` 應由後端執行。
- 目前遊戲選項、交易類型與顯示文字仍有合併或命名差異，正式對帳應依後端契約。

## 14. 待產品確認
