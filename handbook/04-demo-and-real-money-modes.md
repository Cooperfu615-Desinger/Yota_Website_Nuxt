# 第四章：試玩模式與真錢模式

- 章節狀態：草稿，待產品確認
- 版本：0.1
- 建立日期：2026-07-31
- 適用對象：產品營運人員、客服人員
- 對應功能：試玩模式、真錢模式、儲值幣、活動幣、銅幣、模式切換
- 相關章節：第三章「遊戲大廳與遊戲進行方式」、第五章「錢包與遊戲幣別」、第六章「儲值與付款」

## 1. 本章目的

本章說明試玩模式與真錢模式的差異，讓營運與客服能清楚回答玩家以下問題：

- 試玩需要登入嗎？
- 試玩和真錢遊玩使用的幣別是否相同？
- 試玩贏到的點數可以轉成金幣或提領嗎？
- 真錢模式會使用哪些錢包？
- 活動金幣、活動銀幣算不算真錢？
- 為什麼真錢模式需要登入、選擇錢包？
- 玩家誤選真錢模式或發生遊戲中斷時，客服要怎麼處理？

本章的核心原則是：

> 試玩模式只用於體驗遊戲，不產生可兌現的現金價值；真錢模式會使用正式錢包並產生真實的下注、派彩與帳務紀錄。銅幣是無價值試玩幣，不得被說明為真錢或可提款資產。

## 2. 兩種模式快速比較

| 比較項目 | 試玩模式 | 真錢模式 |
|---|---|---|
| 主要目的 | 讓玩家體驗遊戲玩法與畫面 | 使用正式遊戲幣別進行遊戲 |
| 是否涉及儲值資金 | 不應涉及 | 可能涉及玩家儲值幣或正式活動幣 |
| 登入條件 | 正式是否需要訪客 session 待確認；目標上應降低體驗門檻 | 必須登入會員帳號 |
| 使用來源 | 銅幣或正式定義的試玩額度 | 儲值金幣、儲值銀幣、活動金幣或活動銀幣，依遊戲資格與錢包狀態決定 |
| 是否需要選擇錢包 | 通常不需要選擇正式錢包 | 啟動前需要選擇本次使用的錢包來源 |
| 是否產生正式 BET／WIN 帳務 | 不應產生正式資金交易 | 會產生正式下注、派彩與餘額異動紀錄 |
| 贏得的結果 | 僅供試玩，不可兌換現金或正式幣別 | 依遊戲規則與錢包來源進行正式結算 |
| 是否可轉成其他幣別 | 不可將試玩結果兌換成金幣、銀幣或現金 | 僅能使用正式規則允許的錢包與兌換流程 |
| 是否可外部提款 | 不適用 | 平台不提供外部提款或現金兌換 |
| 中斷後處理 | 以試玩 session 狀態為準 | 以正式遊戲、錢包與交易紀錄確認，不可直接承諾取消或退款 |

上表是客服快速判斷用。若正式版本對試玩登入、試玩額度或活動幣使用方式有調整，應以產品確認後的版本更新本章。

## 3. 正式產品規則

### 3.1 試玩模式

- 試玩模式的目的，是讓玩家在不使用正式儲值資金的情況下體驗遊戲。
- 試玩結果不代表正式遊戲的中獎機率、實際派彩或正式帳務結果。
- 試玩所產生的點數或遊戲內餘額不得兌換成金幣、銀幣、台幣或其他現金價值。
- 試玩結果不得轉入玩家正式錢包，也不得作為儲值、提領、贈禮或兌換的來源。
- 銅幣是無價值試玩幣，不具現金或可兌換價值。
- 試玩模式的登入、訪客 session、每日額度、可使用遊戲與資料保存方式，仍需依正式產品決策補齊。

> 規格確認注記（2026-08-03，待確認資料模型）
>
> 目前取得的規格資訊：試玩帳號由聚合商派發 DEMO 帳號進入遊戲試玩，平台本身不產生任何試玩帳號。
>
> 尚待產品、後端與聚合商確認：
> - 此規則是否適用所有遊戲供應商，或只有部分供應商採用。
> - 平台在試玩流程中只負責產生啟動資訊，還是仍會建立平台側的訪客／試玩 session。
> - 試玩餘額、試玩勝負與試玩紀錄是否完全由聚合商管理。
> - 聚合商 DEMO 帳號模式是否與平台銅幣模式並存；若不並存，現有銅幣相關文案與錢包模型需調整。

在上述資料模型確認前，「銅幣」只能作為目前手冊中的待確認試玩資產概念，不應直接向玩家說明所有試玩都由平台銅幣提供。

> - 用途：確認試玩按鈕、試玩模式標示，以及 DEMO 帳號／銅幣尚未定案時不會互相誤導的畫面。
> - 狀態：待正式資料模型確認後補截圖。

### 3.2 真錢模式

- 真錢模式必須先登入會員帳號。
- 真錢模式啟動前，系統應確認玩家資格、遊戲狀態、支援幣別與可用餘額。
- 真錢模式會從玩家選定的正式遊戲錢包來源進行遊戲交易。
- 遊戲不另開獨立子錢包，也不要求玩家手動將餘額轉入遊戲；下注與派彩會即時與平台單一錢包服務交換。
- 真錢模式的每筆下注與派彩，應以正式遊戲與錢包交易紀錄為準。
- 平台提供儲值，但不提供外部提款或現金兌換。

「真錢模式」是玩家端的遊戲模式名稱，不代表遊戲畫面內會直接持有台幣或其他法定貨幣。玩家實際使用的是平台定義的遊戲幣別，幣別價值與兌換規則依第五章說明。

### 3.3 三種幣別來源的定位

正式遊戲錢包以「幣別 × 來源」區分，客服不可只用「餘額」兩個字判斷玩家使用的資產種類。

| 類型 | 正式定位 | 是否可用於真錢遊戲 | 是否可直接兌現 |
|---|---|---|---|
| 儲值金幣 | 玩家儲值後取得的金幣 | 依遊戲支援與帳號資格 | 平台不提供外部現金提款 |
| 儲值銀幣 | 玩家儲值或正式兌換取得的銀幣 | 依遊戲支援與帳號資格 | 平台不提供外部現金提款 |
| 活動金幣 | 以獎勵卡為載體的活動資產，通常附帶流水、上限與期限 | 依獎勵卡與遊戲規則 | 不可直接視為儲值現金；依獎勵卡正式規則處理 |
| 活動銀幣 | 以獎勵卡為載體的活動資產，通常附帶流水、上限與期限 | 依獎勵卡與遊戲規則 | 不可直接視為儲值現金；依獎勵卡正式規則處理 |
| 銅幣 | 無價值試玩幣 | 試玩用途 | 不可兌現、提款或兌換正式幣別 |

所有活動金幣與活動銀幣的派發，一律以獎勵卡作為載體，不存在無卡的活動幣。活動幣的有效流水、轉換上限、到期與回收規則，依獎勵卡章節與正式後端契約處理。

>
> - 放置位置：本節幣別來源表格之後。
> - 用途：確認儲值幣、活動幣、獎勵卡與銅幣／試玩資產的分類方式，避免玩家只看到「餘額」而無法辨識來源。
> - 狀態：待補正式產品截圖。

### 3.4 匯率與整數規則

正式價值比率為：

> NT$ 1：金幣 1：銀幣 100

相關處理規則：

- 金額一律以整數運算。
- 輸入含小數時，先無條件捨去小數部分。
- 捨去後的金額若小於或等於 0，應拒絕該操作。
- 銅幣不適用於現金價值換算。
- 不得將試玩銅幣套用金幣／銀幣匯率換算。

> **截圖預留｜04-3.4-01｜金額、幣別與整數處理提示**

> - 用途：確認儲值／兌換等相關畫面是否正確顯示金額、幣別、捨去小數與無效金額提示。

## 4. 試玩模式操作流程

### 4.1 進入試玩

1. 玩家進入遊戲大廳。
2. 找到想體驗的遊戲。
3. 點擊遊戲卡片上的「試玩」。
4. 系統確認該遊戲是否提供試玩。
5. 系統啟動試玩遊戲 session。
6. 玩家進入遊戲畫面，使用試玩額度體驗玩法。

正式產品若要求訪客 session 或年齡確認，系統會在第 3 至第 5 步之間補上對應檢查；客服應依正式版本畫面引導，不要把目前前端直接進入試玩的行為視為唯一規則。

### 4.2 試玩中的操作

玩家可以依遊戲提供的功能進行試玩，例如查看規則、選擇示範下注額或執行遊戲操作。試玩畫面中的餘額只代表試玩 session 的遊戲數值，不代表玩家正式錢包餘額。

客服需特別提醒：

- 試玩中的勝負不會改變儲值金幣、儲值銀幣、活動金幣或活動銀幣。
- 試玩中的餘額不會轉入會員錢包。
- 試玩中的中獎畫面不代表正式遊戲一定會出現相同結果。
- 試玩畫面中的遊戲幣標示，不能直接解讀為台幣或可提款金額。

>

> - 用途：確認試玩模式、試玩額度／餘額、遊戲名稱與不可兌現說明是否清楚可見。
> - 狀態：待補正式產品截圖。

### 4.3 試玩結束

1. 玩家按下返回大廳、關閉遊戲或離開頁面。
2. 試玩 session 結束或依正式規則保存暫存狀態。
3. 玩家返回遊戲大廳。

試玩結束後，試玩餘額是否保留、是否重置與保存多久，需以正式試玩 session 規則為準。客服不得承諾玩家下次一定會保留目前試玩餘額。

## 5. 真錢模式操作流程

### 5.1 啟動真錢模式

1. 玩家進入遊戲大廳。
2. 找到想遊玩的遊戲。
3. 點擊「真錢玩」。
4. 未登入玩家先完成會員登入。
5. 系統重新確認玩家的年齡確認、帳號狀態與遊戲資格。
6. 系統確認遊戲目前可用的幣別來源。
7. 系統顯示遊戲啟動視窗。
8. 玩家選擇本次遊戲使用的錢包。
9. 玩家確認遊戲名稱、模式與幣別。
10. 玩家按下「進入遊戲」。
11. 系統取得一次性遊戲啟動 URL 或 launch token。
12. 啟動成功後進入正式遊戲。

### 5.2 啟動前玩家應確認的事項

玩家在啟動前應確認：

- 畫面標示的是「真錢模式」。
- 遊戲名稱與供應商正確。
- 選擇的錢包來源正確。
- 使用的幣別正確。
- 顯示的可用餘額足以支應遊戲操作。
- 玩家了解正式遊戲會產生真實的錢包與遊戲紀錄。

客服不能替玩家決定應使用哪一個錢包，也不能因玩家誤選錢包就直接承諾可以取消已完成的下注或交易。

> - 狀態：待補正式產品截圖。

### 5.3 真錢遊戲中的資金流向

正式單一錢包架構下：

1. 玩家啟動遊戲時選擇一個可用的 wallet bucket。
2. 遊戲供應商送出下注事件。
3. 平台錢包即時處理下注扣款。
4. 遊戲供應商送出中獎或結算事件。
5. 平台錢包依正式結果處理派彩或其他狀態。
6. 玩家可在遊戲紀錄與交易紀錄查看正式結果。

這不是「儲值 → 遊戲子錢包 → 提領」的流程。遊戲不另開子錢包，也不提供從遊戲直接提領現金的功能。

> - 狀態：待補正式產品截圖。

### 5.4 真錢模式結束

1. 玩家完成一局或離開遊戲。
2. 遊戲供應商送出最後的下注、派彩或結算事件。
3. 系統保存遊戲與錢包紀錄。
4. 玩家返回大廳或會員頁面。
5. 若畫面餘額與正式紀錄尚未同步，系統應重新整理或重新查詢正式錢包資料。

離開遊戲不等於取消已送出的下注，也不代表尚未結算的局一定會退款。若玩家有爭議，必須查詢正式遊戲與錢包紀錄。

## 6. 模式切換

### 6.1 從試玩切換到真錢

1. 玩家在試玩畫面選擇「真錢模式」。
2. 系統確認玩家是否已登入。
3. 未登入時，開啟登入或註冊流程。
4. 登入成功後，系統要求玩家重新確認遊戲與錢包。
5. 玩家選擇正式錢包。
6. 系統建立新的真錢遊戲 session。

試玩餘額、試玩勝負與試玩中獎結果不會自動轉入真錢錢包。

## 8. 客服處理原則

### 8.1 玩家表示「我只是試玩，為什麼扣款」

客服先確認：

1. 玩家當時按下的是「試玩」或「真錢玩」。
2. 遊戲畫面是否標示真錢模式。
3. 是否曾在啟動視窗選擇儲值或活動錢包。
4. 是否已產生 BET、WIN 或其他正式交易紀錄。
5. 發生時間、遊戲名稱、局號與交易編號。

確認前不得直接說明「一定沒有扣款」或「一定可以退款」。

> **截圖預留｜04-8.1-01｜模式、錢包與交易狀態確認畫面**
>
> - 放置位置：本節客服確認清單之後。
> - 用途：確認客服需要比對的模式標示、錢包來源、BET／WIN、局號與交易編號欄位。
> - 狀態：待補正式查詢畫面；若玩家端無此資訊，應標記為內部查詢畫面。
> - 注意：不得截取或保存密碼、驗證碼、完整 launch token 或不必要的個資。

### 8.2 玩家表示「真錢遊戲沒有獲利」

客服應說明：

- 真錢模式代表會產生正式下注與結算，不代表保證獲利。
- RTP、最大倍率或活動標籤都不代表個人一定獲利。
- 每局結果依遊戲規則與正式結算紀錄為準。
- 若玩家認為帳務或結算不正確，請提供遊戲與交易資訊進行查詢。

客服不得鼓勵玩家加大下注、追損、借款遊玩或以保證獲利方式繼續遊戲。

### 8.3 玩家詢問可否提款

客服標準說法：

- 平台可以進行正式儲值與遊戲幣別管理。
- 平台不提供外部提款或現金兌換。
- 保險箱取回主錢包是平台內部資金移動，不是提領到銀行或現金帳戶。
- 銅幣與試玩結果不具現金價值。

## 9. 客服檢查清單

處理試玩／真錢爭議時，客服依序確認：

1. 玩家使用的模式。
2. 遊戲名稱、供應商與遊戲 key（若可取得）。
3. 是否已登入會員。
4. 真錢模式下使用的錢包來源與幣別。
5. 遊戲啟動時間、下注時間與中斷時間。
6. 是否有 BET、WIN、退款或其他正式交易紀錄。
7. 是否涉及活動金幣、活動銀幣或獎勵卡。
8. 是否顯示維護、資格不足、幣別不支援或餘額不足。
9. 玩家是否要求轉換、提款、退款或取消交易。
10. 是否可提供局號、交易編號、畫面截圖與錯誤訊息。

客服不得要求：

- 玩家提供完整啟動 URL 或 launch token。
- 玩家提供帳號密碼、驗證碼或支付安全資訊。
- 玩家重複下注以測試是否扣款。
- 玩家以其他模式繞過 VIP、年齡、幣別或餘額限制。

## 10. 升級條件

符合以下任一情況，應建立案件或升級給產品、技術、錢包或遊戲供應商團隊：

- 試玩模式產生正式儲值錢包的 BET 或扣款紀錄。
- 真錢模式沒有產生應有的交易紀錄，或玩家餘額與正式交易不一致。
- 玩家明確選擇試玩，但正式系統啟動成真錢 session。
- 玩家明確選擇真錢，但畫面或紀錄顯示為試玩 session。
- 銅幣可以被兌換、提款、贈送或被顯示成具現金價值的幣別。
- 試玩勝負或餘額出現在正式錢包、交易紀錄、排行榜或獎勵計算中。
- 活動幣使用時未依獎勵卡流水、上限或到期規則處理。
- 玩家在模式切換、遊戲斷線或重新連線後出現重複扣款或漏派彩。
- 玩家要求取消已送出的真錢下注或要求保證退款。
- 正式遊戲頁、儲值頁或客服文案把「真錢模式」說成可直接提款。

升級時附上：玩家識別資訊、遊戲名稱、模式、錢包來源、幣別、時間、局號、交易編號、錯誤訊息、操作步驟與是否可重現。不得附上密碼、驗證碼或完整 launch token。

## 11. 客服回覆範例

### 11.1 試玩與真錢差異

> 試玩模式是用來體驗遊戲玩法，不會使用正式儲值資金，試玩中的勝負或餘額也不能兌換成金幣、銀幣或現金。真錢模式則需要登入會員，並在進入遊戲前選擇可用的正式錢包。

### 11.2 銅幣說明

> 銅幣是平台提供的無價值試玩幣，只能依正式規則用於試玩，不具現金或兌換價值，也不能提領或換成金幣、銀幣。

### 11.3 活動幣說明

> 活動金幣與活動銀幣是活動獎勵資產，會依獎勵卡規則受到流水、使用期限或轉換上限等條件限制，不能直接等同儲值金幣或儲值銀幣。實際條件請以該張獎勵卡的規則為準。

### 11.4 真錢模式需要登入

> 真錢遊玩需要先登入會員帳號，因為遊戲中的下注、派彩與餘額異動都必須記錄到您的正式帳號。登入後請確認遊戲名稱與使用幣別，再按下進入遊戲。

### 11.5 試玩結果不能兌換

> 試玩中的中獎或餘額只屬於試玩遊戲狀態，不具正式資產價值，無法轉入您的金幣、銀幣、活動幣或現金帳戶。

### 11.6 平台是否可以提款

> 平台提供遊戲幣別與儲值功能，但不提供外部提款或現金兌換。保險箱取回主錢包也只是平台內部的資金移動，不是提領到銀行或現金帳戶。

### 11.7 玩家誤選真錢模式

> 請先停止繼續下注，並提供遊戲名稱、發生時間、使用幣別、局號或交易編號。我們會先依遊戲與錢包紀錄確認實際狀態；在確認完成前，無法直接承諾取消、退款或補發。

## 12. 目前系統差異（僅供內部參考）

以下內容不是正式產品說法：

- 目前前端點擊試玩會直接進入示範 URL，未必建立正式訪客 session；正式試玩是否需要匿名或訪客識別仍待確認。

- 正式截圖應以產品確認後的實際畫面為準；目前前端 Mock、佔位 URL 與測試餘額不可直接作為正式說明證據。

- 截圖前應遮蔽個人資料、驗證碼、密碼、token、交易敏感欄位與其他玩家資料。
